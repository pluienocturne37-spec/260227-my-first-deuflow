    그래프가 살아 움직인다 — 일차·이차함수 그래프 그리기¶

    Part 6. 공통수학2 — 함수, 알고리즘의 심장을 만나다 | 17차시

    🎯 이 장에서 배우는 것¶

    • 일차함수 y=ax+b에서 기울기(a)와 y절편(b)의 의미를 설명할 수 있다
    • 이차함수 y=ax²의 그래프가 a의 부호와 크기에 따라 달라짐을 확인할 수 있다
    • 엔트리에서 슬라이더로 계수를 조절하면 실시간으로 그래프가 변하는 프로그램을 만들 수 있다

    📚 핵심 개념¶

    🔍 생각해보기¶

    유튜브 채널을 운영한다고 상상해 봅시다. 어떤 채널은 매달 구독자가 100명씩 꾸준히 늘어납니다. 또 다른 채널은 바이럴 영상 하나가 터지면서 처음엔 느리다가 점점 더 빠르게 구독자가 폭증합니다. 이 두 성장 패턴을 그래프로 그리면 어떤 모양일까요?

    첫 번째는 직선(일차함수), 두 번째는 곡선(이차함수)입니다!

    개념 1: 일차함수 y = ax + b¶

    비유로 시작 🚶

    일차함수는 마치 에스컬레이터와 같아요. 한 걸음마다 올라가는 높이가 항상 똑같죠. 기울기(a)는 에스컬레이터의 경사, y절편(b)은 에스컬레이터를 타기 시작하는 층수입니다.

    정확한 정의

    • 기울기 a: x가 1 증가할 때 y가 변하는 양. a가 양수면 오른쪽 위로, 음수면 오른쪽 아래로 향합니다
    • y절편 b: 그래프가 y축과 만나는 점(x=0일 때 y값)

    예시로 확인

    • y = 2x + 1 → 기울기 2(x가 1 늘면 y는 2 늘어남), y절편 1(y축과 (0,1)에서 만남)
    • y = -x + 3 → 기울기 -1(x가 1 늘면 y는 1 줄어듦), y절편 3
    graph LR A["기울기 a > 0"] --> B["오른쪽 위로 ↗"] C["기울기 a < 0"] --> D["오른쪽 아래로 ↘"] E["기울기 a = 0"] --> F["수평선 →"] G["y절편 b"] --> H["그래프의 시작 높이"]

    개념 2: 이차함수 y = ax²¶

    비유로 시작 🎢

    이차함수는 마치 롤러코스터의 U자 구간과 같아요. 내려갈 때 점점 빨라지고, 올라갈 때 점점 느려지죠. 변화율 자체가 변하는 겁니다!

    정확한 정의

    • a > 0: 그래프가 아래로 볼록(∪ 모양, "웃는 얼굴")
    • a < 0: 그래프가 위로 볼록(∩ 모양, "찡그린 얼굴")
    • |a|가 클수록: 그래프가 좁고 뾰족해짐
    • |a|가 작을수록: 그래프가 넓고 완만해짐

    예시로 확인

    • y = x² → 위로 열린 기본 포물선
    • y = 3x² → 더 좁은 포물선(가파르게 상승)
    • y = -0.5x² → 아래로 열린 넓은 포물선
    graph TD subgraph "a의 부호 → 방향" P["a > 0 : ∪ 모양"] N["a < 0 : ∩ 모양"] end subgraph "|a|의 크기 → 폭" BIG["|a| 크다 : 좁고 뾰족"] SMALL["|a| 작다 : 넓고 완만"] end

    💡 알아보기: 일차함수의 변화율은 항상 일정(기울기 a)이지만, 이차함수의 변화율은 x에 따라 달라집니다. 이것이 직선과 곡선의 본질적 차이입니다!

    🔨 따라하기: 엔트리로 인터랙티브 그래프 그리기¶

    엔트리의 펜 기능과 변수 슬라이더를 활용해, 계수를 조절하면 실시간으로 그래프가 변하는 프로그램을 만들어 봅시다.

    Step 1: 변수와 슬라이더 준비¶

    엔트리에서 다음 변수를 만들고, 각각 슬라이더 모드로 설정합니다.

    • 변수 a → 슬라이더 범위: -3 ~ 3 (기울기 또는 이차 계수)
    • 변수 b → 슬라이더 범위: -5 ~ 5 (y절편)
    • 변수 함수종류 → 슬라이더 범위: 1 ~ 2 (1=일차, 2=이차)

    슬라이더를 만드는 방법: 변수 추가 후 실행 화면에서 변수 옆 슬라이더 아이콘을 클릭!

    Step 2: 좌표축 그리기¶

    화면 중앙에 x축과 y축을 그려 좌표 평면을 만듭니다.

    [시작하기를 클릭했을 때]

붓 색깔을 (회색)으로 정하기
붓 굵기를 (1)로 정하기

// x축 그리기
x: (-240), y: (0) 위치로 이동하기
붓 내리기
x: (240), y: (0) 위치로 이동하기
붓 올리기

// y축 그리기
x: (0), y: (-180) 위치로 이동하기
붓 내리기
x: (0), y: (180) 위치로 이동하기
붓 올리기

    Step 3: 그래프 점 찍기 (핵심!)¶

    x를 -10에서 10까지 0.1씩 증가시키면서, 함수 값을 계산해 점을 찍습니다.

    변수 [x값]을 (-10)으로 정하기
붓 색깔을 (빨강)으로 정하기
붓 굵기를 (2)로 정하기

(200)번 반복하기 {

    만약 [함수종류] = (1) 이라면 {
        // 일차함수: y = a*x + b
        변수 [y값]을 ([a] * [x값] + [b])로 정하기
    } 아니면 {
        // 이차함수: y = a*x² + b  
        변수 [y값]을 ([a] * [x값] * [x값] + [b])로 정하기
    }

    // 화면 좌표로 변환 (x20 확대)
    변수 [화면x]를 ([x값] * (20))으로 정하기
    변수 [화면y]를 ([y값] * (20))으로 정하기

    x: [화면x], y: [화면y] 위치로 이동하기
    붓 내리기
    붓 올리기

    변수 [x값]을 (0.1)만큼 바꾸기
}

    💡 왜 20을 곱하나요? 엔트리 화면은 가로 480, 세로 360 픽셀입니다. x값 -10~10을 화면에 꽉 차게 보여주려면 약 20배 확대가 필요합니다.

    Step 4: 실시간 업데이트¶

    슬라이더를 움직일 때마다 그래프가 다시 그려지도록 무한 반복을 추가합니다.

    [시작하기를 클릭했을 때]

}

    Step 5: 실행하고 실험하기 🎮¶

    프로그램을 실행한 후 슬라이더를 조절하며 다음을 확인해 보세요.

    일차함수 실험 (함수종류 = 1) - a를 양수 → 음수로 바꾸면? 직선의 방향이 뒤집힘! - b를 올리면? 그래프가 위로 평행이동!

    이차함수 실험 (함수종류 = 2) - a = 1 → a = 3으로 바꾸면? 포물선이 좁아짐! - a를 양수 → 음수로 바꾸면? ∪ → ∩ 뒤집힘!

    ⚠️ 주의할 점¶

    1. 화면 밖으로 나가는 점 처리 y값이 너무 크거나 작으면(화면y가 ±180을 넘으면) 점이 화면 밖에 찍힙니다. 만약 화면y > -180 이고 화면y < 180 이라면 조건을 추가하면 깔끔해집니다.

    2. 점이 아니라 선으로 연결하기 현재는 점을 하나씩 찍는 방식입니다. 매끄러운 선을 원한다면 붓 올리기를 제거하고, 첫 번째 점에서만 붓 내리기를 하면 점들이 선으로 연결됩니다. 단, 화면 밖의 점을 건너뛸 때는 붓 올리기가 필요합니다.

    ✅ 점검하기¶

    기본 📗

    1. 일차함수 y = -2x + 5에서 기울기와 y절편은 각각 얼마인가요?
    정답 확인 기울기(a) = **-2**, y절편(b) = **5**. x가 1 증가하면 y는 2 감소하고, 그래프는 y축의 (0, 5)를 지나는 오른쪽 아래 방향 직선입니다.

    응용 📘

    1. 이차함수 y = 2x²과 y = 0.5x²의 그래프를 비교할 때, 어느 쪽이 더 좁고 뾰족한가요? 그 이유는?
    정답 확인 **y = 2x²**이 더 좁고 뾰족합니다. |a|의 값이 클수록(2 > 0.5) 같은 x값에서 y값이 더 크게 변하므로, 그래프가 y축에 더 가깝게 모입니다.

    심화 (도전!) 📕

    1. 엔트리 프로그램을 수정하여 삼차함수 y = ax³의 그래프를 그려보세요. 어떤 모양이 나오나요?
    정답 확인 코드에서 `y값 = a * x값 * x값 * x값`으로 수정하면 됩니다. 삼차함수 그래프는 원점을 기준으로 **S자 곡선**(점대칭) 모양이 나옵니다. a > 0이면 왼쪽 아래에서 오른쪽 위로, a < 0이면 반대 방향입니다.

    🧠 정리하기: 일차함수는 일정한 변화율(직선), 이차함수는 가속하는 변화율(곡선)을 가집니다. 슬라이더 하나로 계수를 바꿔 그래프가 실시간으로 변하는 프로그램을 만들어 보면, 수식 속 숫자 하나가 그래프의 모양을 얼마나 극적으로 바꾸는지 체감할 수 있습니다!
