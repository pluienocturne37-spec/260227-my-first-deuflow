    합성함수와 역함수 — 코딩의 함수처럼 연결하기¶

    Part 6. 공통수학2 — 함수, 알고리즘의 심장을 만나다 | 18차시

    🎯 이 장에서 배우는 것¶

    • 합성함수 f(g(x))가 함수를 파이프라인처럼 연결하는 것임을 설명할 수 있다
    • 역함수가 되돌리기(Undo) 기능과 같은 원리임을 이해할 수 있다
    • 코드로 온도 변환기(섭씨↔화씨)를 만들어 합성함수와 역함수를 체험할 수 있다

    📚 핵심 개념¶

    🔑 개념 1: 합성함수 — 함수를 연결하는 파이프라인¶

    비유로 시작 💡

    스마트폰에서 사진 필터를 적용해 본 적 있나요? "밝기 올리기" 필터를 적용한 뒤, "흑백 변환" 필터를 또 적용하면 — 두 필터가 순서대로 연결되어 하나의 결과를 만들어냅니다. 합성함수는 바로 이것과 같습니다!

    정확한 정의

    두 함수 f와 g가 있을 때, g를 먼저 적용하고 그 결과에 f를 적용하는 새로운 함수를 합성함수라 하고, (f∘g)(x) = f(g(x)) 로 씁니다.

    📌 읽는 순서 주의! f(g(x))는 "g 먼저, f 나중"입니다. 코드에서 안쪽 함수가 먼저 실행되는 것과 똑같아요.

    예시로 확인

    g(x) = x + 3, f(x) = 2x일 때, f(g(2))를 구해봅시다.

    • 1단계: g(2) = 2 + 3 = 5 (g를 먼저!)
    • 2단계: f(5) = 2 × 5 = 10 (그 결과에 f를!)
    • 결과: f(g(2)) = 10
    flowchart LR A["입력: 2"] -->|"g(x) = x + 3"| B["5"] B -->|"f(x) = 2x"| C["출력: 10"]

    🤔 생각해보기: 순서를 바꿔서 g(f(2))를 구하면? f(2) = 4, g(4) = 7로, 결과가 달라집니다! 합성함수는 순서가 중요해요.

    🔑 개념 2: 역함수 — Ctrl+Z 되돌리기¶

    비유로 시작 💡

    문서를 작성하다 실수하면 Ctrl+Z를 누르죠? 역함수는 바로 이 "되돌리기" 버튼입니다. 함수 f가 어떤 작업을 했다면, 역함수 f⁻¹은 그 작업을 정확히 원래대로 되돌리는 함수입니다.

    정확한 정의

    함수 f에 대해, f(a) = b일 때 f⁻¹(b) = a가 되는 함수 f⁻¹을 f의 역함수라 합니다. 핵심 성질은 다음과 같습니다.

    • f⁻¹(f(x)) = x → 실행 후 되돌리면 원래 값
    • f(f⁻¹(x)) = x → 되돌린 후 실행해도 원래 값
    flowchart LR A["섭씨 25°C"] -->|"f: 섭씨→화씨"| B["화씨 77°F"] B -->|"f⁻¹: 화씨→섭씨"| C["섭씨 25°C 🔄"]

    예시로 확인: 온도 변환

    • f(x) = 9/5 · x + 32 (섭씨 → 화씨)
    • f⁻¹(x) = 5/9 · (x − 32) (화씨 → 섭씨, 되돌리기!)

    f(25) = 9/5 × 25 + 32 = 77, f⁻¹(77) = 5/9 × (77 − 32) = 25 ← 원래 값으로 돌아왔습니다!

    📌 역함수가 존재하려면? 함수가 일대일대응(서로 다른 입력이 서로 다른 출력을 가질 때)이어야 합니다. 되돌릴 때 "어디로 돌아가야 하지?" 하고 헷갈리면 안 되니까요.

    🔨 따라하기: 온도 변환기 만들기¶

    Step 1: 섭씨→화씨 함수 만들기¶

    def celsius_to_fahrenheit(c):
    """섭씨를 화씨로 변환하는 함수 f"""
    return 9/5 * c + 32

# 테스트
print(celsius_to_fahrenheit(0))    # 물의 어는점
print(celsius_to_fahrenheit(100))  # 물의 끓는점

    실행 결과: 

    32.0
212.0

    Step 2: 화씨→섭씨 역함수 만들기¶

    def fahrenheit_to_celsius(f):
    """화씨를 섭씨로 되돌리는 역함수 f⁻¹"""
    return 5/9 * (f - 32)

# 테스트
print(fahrenheit_to_celsius(32))
print(fahrenheit_to_celsius(212))

    실행 결과: 

    0.0
100.0

    Step 3: 합성해서 되돌아오는지 확인하기¶

    역함수의 핵심 — f⁻¹(f(x)) = x가 정말 성립할까요?

    original = 25  # 원래 섭씨 온도

# 합성: 역함수(함수(원래값)) = 원래값?
converted = celsius_to_fahrenheit(original)      # f(25) = 77
restored = fahrenheit_to_celsius(converted)      # f⁻¹(77) = ?

print(f"원래 값: {original}°C")
print(f"화씨 변환: {converted}°F")
print(f"다시 섭씨로: {restored}°C")
print(f"원래 값과 같은가? {original == restored}")

    실행 결과: 

    원래 값: 25°C
화씨 변환: 77.0°F
다시 섭씨로: 25.0°C
원래 값과 같은가? True

    🎉 성공! 함수를 적용하고 역함수로 되돌리니 원래 값 25가 정확히 돌아왔습니다.

    Step 4: 합성함수 만들어보기¶

    이번엔 서로 다른 두 함수를 합성해봅시다. g(x) = x + 3, f(x) = 2x로 f(g(x))를 코드로 구현합니다.

    def g(x):
    return x + 3

def f(x):
    return 2 * x

def composite_fg(x):
    """합성함수 f(g(x)) — g 먼저, f 나중"""
    return f(g(x))

# 여러 값으로 테스트
for val in [0, 1, 2, 5]:
    print(f"f(g({val})) = f({g(val)}) = {composite_fg(val)}")

    실행 결과: 

    f(g(0)) = f(3) = 6
f(g(1)) = f(4) = 8
f(g(2)) = f(5) = 10
f(g(5)) = f(8) = 16

    📝 전체 코드¶

    # === 온도 변환기: 합성함수와 역함수 체험 ===

# 함수 정의
def celsius_to_fahrenheit(c):
    """섭씨→화씨 변환 함수 f"""
    return 9/5 * c + 32

def fahrenheit_to_celsius(f):
    """화씨→섭씨 역함수 f⁻¹"""
    return 5/9 * (f - 32)

# 역함수 검증: f⁻¹(f(x)) = x
print("=== 역함수 검증 ===")
for temp in [0, 25, 36.5, 100]:
    converted = celsius_to_fahrenheit(temp)
    restored = fahrenheit_to_celsius(converted)
    print(f"{temp}°C → {converted}°F → {restored}°C ✅")

# 합성함수 체험: g 먼저, f 나중
print("\n=== 합성함수 f(g(x)) ===")
def g(x): return x + 3
def f(x): return 2 * x

for val in [0, 1, 2, 5]:
    print(f"f(g({val})) = {f(g(val))}")

    ⚠️ 주의할 점¶

    1. 합성 순서를 헷갈리지 마세요!

    f(g(x))에서는 안쪽 g가 먼저 실행됩니다. 수학 표기 f∘g는 "f 다음 g"가 아니라 "g 먼저, 그 다음 f"입니다. 코드에서 f(g(x))를 보면 자연스럽죠 — 괄호 안쪽부터 실행되니까요!

    2. 모든 함수에 역함수가 있는 건 아닙니다!

    f(x) = x²은 f(4) = 16이지만 f(−4)도 16입니다. 16에서 되돌릴 때 4인지 −4인지 알 수 없으므로 역함수가 존재하지 않습니다(일대일대응이 아닌 경우).

    ✅ 점검하기¶

    1️⃣ [기본] f(x) = 3x, g(x) = x − 1일 때, f(g(4))의 값은?

    정답 확인 g(4) = 4 − 1 = 3, f(3) = 3 × 3 = **9**

    2️⃣ [응용] f(x) = 2x + 5의 역함수 f⁻¹(x)를 구하세요.

    정답 확인 y = 2x + 5에서 x에 대해 풀면: x = (y − 5) / 2 따라서 **f⁻¹(x) = (x − 5) / 2** 검증: f⁻¹(f(3)) = f⁻¹(11) = (11−5)/2 = 3 ✅

    3️⃣ [심화·도전] 환율 변환 합성함수 문제

    원→달러 변환 함수 g(x) = x / 1300, 달러→유로 변환 함수 f(x) = 0.92x 일 때, 130,000원은 몇 유로인지 f(g(x))로 구하세요.

    정답 확인 g(130000) = 130000 / 1300 = 100달러 f(100) = 0.92 × 100 = **92유로** 합성함수로 한 번에: f(g(x)) = 0.92 × (x / 1300) = 0.92x / 1300 f(g(130000)) = 0.92 × 130000 / 1300 = **92유로** ✅

    📌 정리하기: 이번 장의 핵심 - 합성함수 f(g(x)): 함수를 파이프라인처럼 연결. 안쪽(g) 먼저, 바깥(f) 나중! - 역함수 f⁻¹: Ctrl+Z처럼 되돌리기. f⁻¹(f(x)) = x - 역함수가 존재하려면 일대일대응이어야 함
