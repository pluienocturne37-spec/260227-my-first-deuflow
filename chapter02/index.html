    변수란 무엇일까? — 게임 HP 바 직접 만들기¶

    [1권] Part 1. 출발선 — 수학과 코딩이 만나는 순간 | 2차시

    🎯 이 장에서 배우는 것¶

    • 수학의 '변수'와 코딩의 '변수'가 같은 개념임을 설명할 수 있다
    • 엔트리에서 변수를 만들고, 값을 저장하거나 바꿀 수 있다
    • HP 바 시뮬레이션을 통해 변수의 변화를 눈으로 확인할 수 있다

    📚 핵심 개념¶

    🎮 시작하기 전에 — HP는 어디에 저장될까?¶

    발로란트, 마인크래프트, 브롤스타즈… 어떤 게임이든 캐릭터에게는 HP(체력)가 있습니다. 적에게 맞으면 HP가 줄어들고, 회복 아이템을 먹으면 HP가 올라가죠.

    🤔 생각해보기: 게임 속 HP 숫자는 대체 어디에 담겨 있을까요? 그리고 어떻게 줄었다 늘었다 할 수 있을까요?

    그 비밀이 바로 오늘 배울 변수입니다.

    개념 1: 변수 — 이름표가 붙은 상자¶

    ① 비유로 시작

    변수는 마치 이름표가 붙은 상자와 같아요. 상자 안에 숫자나 글자를 넣어 두고, 필요할 때 꺼내 보거나 다른 값으로 바꿀 수 있습니다.

    graph LR A["📦 상자 이름: HP"] -->|안에 들어있는 값| B["100"] C["📦 상자 이름: 이름"] -->|안에 들어있는 값| D["제트"]

    ② 정확한 정의

    변수(Variable): 값을 저장해 두는 공간에 이름을 붙인 것. 프로그램이 실행되는 동안 그 값이 변할 수 있다.

    ③ 예시로 확인

    • 상자 이름이 HP이고, 안에 100이 들어 있다 → HP는 100
    • 적에게 맞아서 안의 값을 70으로 바꾼다 → HP는 70
    • 회복해서 90으로 바꾼다 → HP는 90

    상자 자체(이름)는 그대로인데, 안에 든 값만 변하는 것이 핵심입니다!

    개념 2: 수학 변수 = 코딩 변수¶

    수학 시간에 이런 식을 본 적 있죠?

    x + 3 = 7 → x는 4

    여기서 x도 "어떤 값이 들어갈 자리"입니다. 코딩의 변수와 본질이 같아요.

    graph TB subgraph 수학 M1["x = 4"] M2["x에 4라는 값이 대응"] end subgraph 코딩 C1["HP = 100"] C2["HP라는 상자에 100을 저장"] end M1 -.->|같은 원리| C1

    차이점 하나만 기억하세요:

    • 수학: x = 4는 "x와 4가 같다"는 뜻 (등호 = 같다)
    • 코딩: HP = 100은 "HP 상자에 100을 넣어라"는 뜻 (등호 = 저장하라)

    📌 알아보기: 코딩에서 =는 "같다"가 아니라 "오른쪽 값을 왼쪽 상자에 넣어라"라는 명령입니다. 이것을 대입(할당)이라고 부릅니다.

    🔨 따라하기 — HP 바 만들기 (엔트리)¶

    지금부터 엔트리에서 키보드를 누르면 HP가 변하는 HP 바를 직접 만들어 봅시다!

    Step 1: 엔트리에 접속하고 새 작품 만들기¶

    1. 브라우저에서 playentry.org 에 접속합니다.
    2. 만들기 버튼을 눌러 새 작품을 시작합니다.
    3. 기본 엔트리봇 캐릭터가 화면에 보이면 준비 완료!

    Step 2: 변수 만들기¶

    1. 왼쪽 블록 꾸러미에서 "자료" 카테고리를 클릭합니다.
    2. "변수 추가하기" 버튼을 누릅니다.
    3. 변수 이름에 HP를 입력하고 확인을 누릅니다.

    💡 화면 왼쪽 위에 HP : 0이라는 표시가 나타나면 성공! 이것이 바로 변수 모니터입니다. 값이 바뀌면 실시간으로 보여줍니다.

    Step 3: HP 초기값 설정하기¶

    게임이 시작되면 HP를 100으로 세팅해야겠죠?

    블록 조립 (엔트리 블록 순서):

    🟢 시작하기 버튼을 클릭했을 때
   ├─ HP 를 [100] 으로 정하기
   └─ [HP는 100! 게임 시작!] 을(를) 말하기 (2초)

    ▶ 버튼을 눌러 실행하면, 변수 모니터에 HP : 100이 표시됩니다.

    Step 4: 키보드로 HP 줄이고 늘리기¶

    이제 핵심! 키보드 입력에 따라 HP가 변하도록 만듭니다.

    블록 조립 (엔트리 블록 순서):

    🟢 시작하기 버튼을 클릭했을 때
   ├─ HP 를 [100] 으로 정하기
   └─ 계속 반복하기
        ├─ 만약 [a 키를 눌렀는가?] 라면
        │    ├─ HP 를 [-10] 만큼 바꾸기
        │    └─ [으악! 피격!] 을(를) 말하기 (0.5초)
        └─ 만약 [s 키를 눌렀는가?] 라면
             ├─ HP 를 [15] 만큼 바꾸기
             └─ [회복 중...] 을(를) 말하기 (0.5초)

    실행 결과:

    [a 키 누름] → HP : 100 → 90 → 80 → 70 ...
[s 키 누름] → HP : 70 → 85 → 100 ...

    📌 "~로 정하기"와 "~만큼 바꾸기"의 차이를 꼭 구분하세요! - 정하기: 상자 안을 완전히 새 값으로 교체 (HP = 100) - 바꾸기: 현재 값에서 더하거나 빼기 (HP = HP - 10)

    Step 5: HP가 0 이하면 게임 오버!¶

    HP가 마이너스로 내려가면 이상하겠죠? 조건을 추가합니다.

    계속 반복하기 안에 추가:

    만약 [HP ≤ 0] 이라면
   ├─ HP 를 [0] 으로 정하기
   ├─ [게임 오버!] 을(를) 말하기 (2초)
   └─ 모든 코드 멈추기

    이제 HP가 0 이하로 떨어지면 게임 오버 메시지가 뜨고 멈춥니다! 🎮

    📝 전체 코드 (엔트리 블록 전체 구조)¶

    🟢 시작하기 버튼을 클릭했을 때

  HP 를 [100] 으로 정하기
  [HP는 100! 게임 시작!] 을(를) 말하기 (2초)

  계속 반복하기
  │
  ├─ 만약 [a 키를 눌렀는가?] 라면
  │    ├─ HP 를 [-10] 만큼 바꾸기
  │    └─ [으악! 피격!] 을(를) 말하기 (0.5초)
  │
  ├─ 만약 [s 키를 눌렀는가?] 라면
  │    ├─ HP 를 [15] 만큼 바꾸기
  │    └─ [회복 중...] 을(를) 말하기 (0.5초)
  │
  └─ 만약 [HP ≤ 0] 이라면
       ├─ HP 를 [0] 으로 정하기
       ├─ [게임 오버!] 을(를) 말하기 (2초)
       └─ 모든 코드 멈추기

    ⚠️ 주의할 점¶

    1. "정하기"와 "바꾸기"를 헷갈리지 마세요!

    • HP를 100으로 정하기 → HP가 무조건 100이 됨
    • HP를 -10만큼 바꾸기 → 현재 HP에서 10을 빼줌

    실수로 "정하기"를 써버리면 HP가 항상 같은 값으로 돌아가 버립니다.

    2. 변수 이름은 의미 있게!

    a, b 같은 이름보다 HP, 점수, 속도처럼 무엇을 저장하는지 알 수 있는 이름을 쓰세요. 나중에 코드가 길어지면 헷갈리지 않습니다.

    ✅ 점검하기¶

    기본 문제¶

    1. HP가 100인 상태에서 a 키를 3번 누르면 HP는 얼마일까요?

    정답 확인 **70**입니다. a 키를 누를 때마다 HP가 10씩 줄어듭니다. 100 → 90 → 80 → **70**

    2. 수학에서 x = 5와 코딩에서 x = 5의 차이를 한 문장으로 설명해 보세요.

    정답 확인 수학에서는 "x와 5가 **같다**"는 뜻이고, 코딩에서는 "x라는 상자에 5를 **넣어라(저장하라)**"는 뜻입니다.

    응용 문제¶

    3. HP가 50인 상태에서 아래 동작을 순서대로 했을 때 최종 HP는? - s 키 1번 → a 키 2번 → s 키 1번

    정답 확인 50 → **(+15)** 65 → **(-10)** 55 → **(-10)** 45 → **(+15)** **60**

    🌟 도전 문제¶

    HP 바 옆에 MP(마나) 바를 추가해 보세요! - 새 변수 MP를 만들고 초기값을 50으로 설정 - d 키를 누르면 MP가 20 줄어들면서 "스킬 사용!"이라고 말하기 - f 키를 누르면 MP가 10 회복되면서 "마나 회복!"이라고 말하기 - MP가 0 이하면 "마나 부족!"이라고 말하기

    🔑 핵심 개념 정리¶

    변수 = 이름표가 붙은 상자. 값을 저장하고, 꺼내 쓰고, 바꿀 수 있다.

    수학의 변수(x, y)와 코딩의 변수(HP, 점수)는 "변하는 값을 담는 그릇"이라는 점에서 같은 개념이다.

    정하기 = 새 값으로 통째로 교체 / 바꾸기 = 현재 값에서 더하거나 빼기
