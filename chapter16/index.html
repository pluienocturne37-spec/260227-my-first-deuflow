    함수 = 기계 — 일대일 대응과 자동 번역기¶

    Part 6. 공통수학2 — 함수, 알고리즘의 심장을 만나다 | 16차시 (50분)

    🎯 이 장에서 배우는 것¶

    • 함수의 정의(하나의 입력에 하나의 출력)를 기계 비유로 설명할 수 있다
    • 일대일 함수·상수 함수·항등 함수를 구분할 수 있다
    • 엔트리(파이썬)로 간단한 한→영 단어 번역기를 만들어 함수 대응을 체험할 수 있다

    📚 핵심 개념¶

    🤔 생각해보기¶

    구글 번역기에 '사과'를 넣으면 'apple'이 나옵니다. 그런데 만약 같은 단어를 넣을 때마다 'apple', 'banana', 'grape'처럼 매번 다른 결과가 나온다면? 그런 번역기를 믿고 쓸 수 있을까요?

    절대 못 쓰겠죠! 번역기가 제대로 작동하려면 같은 입력에는 반드시 같은 출력이 나와야 합니다. 이것이 바로 함수의 핵심 규칙입니다.

    개념 1: 함수란 무엇인가?¶

    ① 비유로 시작

    함수는 마치 자판기와 같아요. 500원을 넣고 '콜라' 버튼을 누르면 반드시 콜라만 나옵니다. 같은 버튼을 눌렀는데 어떤 날은 콜라, 어떤 날은 사이다가 나온다면 고장 난 자판기죠!

    ② 정확한 정의

    함수(function): 집합 X의 각 원소에 집합 Y의 원소가 하나씩만 대응하는 관계

    • X를 정의역(입력 모음), Y를 공역(출력 후보 모음)이라 부릅니다
    • 실제로 출력된 값들의 모음을 치역이라 합니다

    ③ 예시로 확인

    flowchart LR subgraph X["정의역 X"] a["사과"] b["바나나"] c["포도"] end subgraph Y["공역 Y"] d["apple"] e["banana"] f["grape"] g["melon"] end a --> d b --> e c --> f

    함수인 이유: 각 한국어 단어가 정확히 하나의 영어 단어에 대응합니다. 'melon'은 아무도 선택하지 않았지만 괜찮습니다 — 공역에 남는 원소가 있어도 함수입니다!

    📌 알아보기: 함수가 아닌 경우

    flowchart LR subgraph X2["입력"] p["사과"] q["바나나"] end subgraph Y2["출력"] r["apple"] s["fruit"] end p --> r p --> s q --> r

    '사과'가 'apple'과 'fruit' 두 곳에 대응 → ❌ 함수가 아닙니다! 하나의 입력에 출력이 두 개 이상이면 안 됩니다.

    개념 2: 함수의 종류 — 세 가지 캐릭터¶

    ① 일대일 함수 (Injective)

    서로 다른 입력 → 서로 다른 출력. 출력이 겹치지 않습니다.

    flowchart LR subgraph 입력 A1["1"] A2["2"] A3["3"] end subgraph 출력 B1["a"] B2["b"] B3["c"] B4["d"] end A1 --> B1 A2 --> B2 A3 --> B3

    1→a, 2→b, 3→c — 출력값이 모두 다릅니다 ✅

    ② 상수 함수 (Constant)

    모든 입력 → 같은 출력. 뭘 넣어도 결과가 하나입니다.

    flowchart LR subgraph 입력2 C1["1"] C2["2"] C3["3"] end subgraph 출력2 D1["7"] end C1 --> D1 C2 --> D1 C3 --> D1

    번역기로 치면, 아무 단어를 넣어도 항상 'hello'만 출력하는 셈이죠. 유용하진 않지만 함수 규칙(하나의 출력)은 지킵니다!

    ③ 항등 함수 (Identity)

    입력 = 출력. 넣은 그대로 나옵니다. f(x) = x

    마치 복사기처럼, 원본을 그대로 돌려주는 함수입니다.

    📋 정리하기: 세 함수 비교

    flowchart TB F["함수의 종류"] F --> I["일대일 함수<br/>서로 다른 입력 → 서로 다른 출력"] F --> C["상수 함수<br/>모든 입력 → 같은 출력 하나"] F --> D["항등 함수<br/>입력 = 출력 (그대로)"]

    🔨 따라하기: 한→영 번역기 만들기¶

    목표: 한국어 단어를 입력하면 대응하는 영어 단어를 출력하는 함수 번역기를 만듭니다.

    Step 1: 단어 쌍 저장하기¶

    함수의 대응 관계를 딕셔너리(사전)로 표현합니다. 딕셔너리란 {키: 값} 형태로 데이터를 저장하는 구조입니다.

    # 한→영 대응 관계 (함수의 정의역 → 치역)
translator = {
    "사과": "apple",
    "바나나": "banana",
    "포도": "grape",
    "딸기": "strawberry",
    "수박": "watermelon"
}

    💡 딕셔너리의 키(key)가 입력(정의역), 값(value)이 출력(치역)입니다.

    Step 2: 입력 받기¶

    word = input("번역할 한국어 단어를 입력하세요: ")

    Step 3: 대응하는 출력 찾기¶

    if word in translator:
    result = translator[word]
    print(f"'{word}' → '{result}'")
else:
    print("등록되지 않은 단어입니다.")

    실행 결과: 

    번역할 한국어 단어를 입력하세요: 사과
'사과' → 'apple'

    Step 4: 함수 규칙 검증하기¶

    같은 입력을 여러 번 넣어도 항상 같은 출력이 나오는지 확인합니다.

    # 함수 규칙 검증: 같은 입력 → 같은 출력?
test_words = ["사과", "포도", "사과", "딸기", "포도"]
for w in test_words:
    print(f"f({w}) = {translator[w]}")

    실행 결과: 

    f(사과) = apple
f(포도) = grape
f(사과) = apple
f(딸기) = strawberry
f(포도) = grape

    ✅ '사과'를 두 번 넣었지만 두 번 다 'apple' — 함수 규칙을 만족합니다!

    Step 5: 함수 종류 판별하기¶

    # 이 번역기는 일대일 함수일까?
outputs = list(translator.values())  # 모든 출력값
if len(outputs) == len(set(outputs)):  # 중복이 없으면
    print("→ 일대일 함수입니다! (출력값이 모두 다름)")
else:
    print("→ 일대일 함수가 아닙니다. (출력값에 중복 있음)")

    실행 결과: 

    → 일대일 함수입니다! (출력값이 모두 다름)

    📝 전체 코드¶

    # === 한→영 번역기 (함수 체험) ===

# 1. 대응 관계 정의
translator = {
    "사과": "apple",
    "바나나": "banana",
    "포도": "grape",
    "딸기": "strawberry",
    "수박": "watermelon"
}

# 2. 번역 함수
def translate(word):
    if word in translator:
        return translator[word]
    else:
        return None

# 3. 실행
print("=== 한→영 번역기 ===")
print(f"등록 단어: {list(translator.keys())}")

word = input("\n번역할 단어: ")
result = translate(word)

if result:
    print(f"f({word}) = {result}")
else:
    print("등록되지 않은 단어입니다.")

# 4. 함수 종류 판별
outputs = list(translator.values())
if len(outputs) == len(set(outputs)):
    print("\n✅ 이 번역기는 일대일 함수입니다.")

# 5. 🚀 도전: 역함수 (영→한)
reverse = {v: k for k, v in translator.items()}
eng = input("\n[역함수] 영어 단어 입력: ")
if eng in reverse:
    print(f"f⁻¹({eng}) = {reverse[eng]}")
else:
    print("등록되지 않은 영어 단어입니다.")

    ⚠️ 주의할 점¶

    1. "출력이 같다"와 "함수가 아니다"를 혼동하지 마세요!

    여러 입력이 같은 출력을 가져도 함수입니다. (예: 1→a, 2→a, 3→a는 상수함수이자 함수) 함수가 아닌 경우는 하나의 입력이 두 개 이상의 출력을 가질 때뿐입니다.

    2. 일대일 함수만 역함수를 가집니다

    상수함수에서 역방향을 시도하면, 하나의 출력에 여러 입력이 대응되어 함수 규칙이 깨집니다. 도전 코드의 역함수가 작동하는 이유는 우리 번역기가 일대일 함수이기 때문입니다.

    ✅ 점검하기¶

    1. (기본) 다음 중 함수인 것을 모두 고르세요. - (가) 1→a, 2→b, 3→a - (나) 1→a, 1→b, 2→c - (다) 1→a, 2→a, 3→a

    정답 확인 **(가) ✅ 함수** — 1과 3이 같은 출력 a를 가지지만, 각 입력마다 출력이 하나이므로 함수입니다. **(나) ❌ 함수 아님** — 입력 1이 a와 b 두 곳에 대응하므로 함수가 아닙니다. **(다) ✅ 함수 (상수함수)** — 모든 입력이 같은 출력 a에 대응하지만, 각 입력의 출력은 하나이므로 함수입니다.

    2. (응용) 위 (가)는 일대일 함수인가요? 이유와 함께 답하세요.

    정답 확인 **아닙니다.** 일대일 함수는 서로 다른 입력이 서로 다른 출력을 가져야 합니다. (가)에서 입력 1과 3이 **같은 출력 a**에 대응하므로 일대일 함수가 아닙니다.

    3. (심화) 코드에서 reverse = {v: k for k, v in translator.items()}가 제대로 작동하려면 원래 함수가 어떤 조건을 만족해야 할까요?

    정답 확인 **일대일 함수**여야 합니다. 만약 "사과"→"apple", "능금"→"apple"처럼 서로 다른 입력이 같은 출력을 가지면, 역방향 딕셔너리에서 "apple" 키에 하나의 값만 저장되어 정보가 유실됩니다. 일대일 대응이어야 역함수가 완전하게 존재합니다.

    📌 핵심 개념 요약

    • 함수 = 하나의 입력에 반드시 하나의 출력이 대응하는 관계
    • 일대일 함수 = 서로 다른 입력 → 서로 다른 출력 (역함수 가능!)
    • 상수 함수 = 모든 입력 → 동일한 출력 하나
    • 항등 함수 = 입력 그대로 출력 (f(x) = x)
    • 프로그래밍의 딕셔너리는 함수의 대응 관계를 그대로 표현합니다

    🔗 다음 장 미리보기¶

    17차시: 합성함수와 역함수 — 기계를 연결하고 되감기

    번역기 하나도 대단하지만, 기계를 연결하면 더 강력해집니다. 한→영 번역기 뒤에 영→일 번역기를 붙이면? 한국어가 바로 일본어로! 이것이 합성함수 f∘g입니다. 그리고 번역을 되돌리는 역함수의 비밀도 파헤쳐 봅니다. 🔄
