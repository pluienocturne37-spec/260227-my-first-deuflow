    21차시. 조건부 확률 — '이미 일어난 일'이 확률을 바꾼다¶

    Part 7. 공통수학2 — 확률, 랜덤의 세계를 지배하다

    🎯 이 장에서 배우는 것¶

    • 조건부 확률의 개념을 '정보가 주어졌을 때 달라지는 확률'로 설명할 수 있다
    • 몬티홀 문제를 통해 조건부 확률의 직관적 이해를 경험할 수 있다
    • 엔트리에서 몬티홀 게임 시뮬레이터를 만들어 바꾸기 전략의 유리함을 검증할 수 있다

    🎪 도입: TV 게임쇼에 나가다!¶

    여러분이 TV 게임쇼에 출연했다고 상상해 보세요.

    무대 위에 문 3개가 있습니다. 하나의 문 뒤에는 🚗 자동차, 나머지 두 문 뒤에는 🐐 염소가 있습니다.

    여러분이 1번 문을 선택했습니다. 그러자 사회자가 3번 문을 열어 보여줍니다. 그 뒤에는 🐐 염소가 있었습니다.

    사회자가 묻습니다.

    "선택을 2번 문으로 바꾸시겠습니까, 아니면 1번 문을 유지하시겠습니까?"

    여러분의 선택은? 🤔

    이것이 수학사에서 가장 뜨거운 논쟁을 일으킨 몬티홀 문제입니다. 정답은 놀랍게도 "바꾸는 것이 2배 유리하다"입니다. 왜 그런지, 조건부 확률로 증명해 봅시다.

    📚 핵심 개념¶

    개념 1: 조건부 확률 P(A|B)¶

    1. 비유로 시작

    조건부 확률은 마치 "안경을 쓰고 세상을 보는 것"과 같아요. 맨눈으로 볼 때와 안경을 쓰고 볼 때 세상이 다르게 보이듯, 새로운 정보(조건)가 주어지면 확률도 달라집니다.

    2. 정확한 정의

    사건 B가 일어났다는 정보가 주어졌을 때, 사건 A가 일어날 확률을 조건부 확률이라 하고 다음과 같이 구합니다.

    P(A|B) = P(A ∩ B) / P(B) (단, P(B) > 0)

    • P(A|B): "B가 일어났을 때 A의 확률" — 세로줄( | )은 "~일 때"로 읽습니다
    • P(A ∩ B): A와 B가 동시에 일어날 확률
    • P(B): 조건이 되는 사건 B의 확률

    3. 예시로 확인

    💡 알아보기: 주사위 하나를 던졌더니 짝수가 나왔다고 합니다. 이때 그 수가 3 이상일 확률은?

    • 전체 표본공간: {1, 2, 3, 4, 5, 6}
    • 사건 B(짝수): {2, 4, 6} → P(B) = 3/6
    • 사건 A(3 이상): {3, 4, 5, 6}
    • A ∩ B(짝수이면서 3 이상): {4, 6} → P(A ∩ B) = 2/6

    P(A|B) = (2/6) / (3/6) = 2/3

    "짝수"라는 정보가 없었다면 3 이상일 확률은 4/6 = 2/3이지만, 항상 같은 건 아닙니다. 정보가 확률을 바꾸는 것, 이것이 조건부 확률의 핵심입니다.

    flowchart LR A["전체 표본공간<br/>{1,2,3,4,5,6}"] -->|"짝수 조건 적용"| B["축소된 세계<br/>{2,4,6}"] B -->|"3 이상?"| C["해당: {4,6}<br/>확률 = 2/3"]

    개념 2: 몬티홀 문제 — 조건부 확률의 꽃¶

    처음 선택할 때 자동차를 맞힐 확률은 1/3, 틀릴 확률은 2/3입니다.

    사회자가 염소 문을 열어준 후 상황을 정리해 봅시다.

    💡 생각해보기: 사회자는 절대 자동차 문을 열지 않습니다. 이 규칙이 핵심입니다!

    경우를 나눠 봅시다 (1번 문을 선택했다고 가정)

    • 경우 ①: 자동차가 1번 뒤에 있음 (확률 1/3) → 바꾸면 ❌, 유지하면 ✅
    • 경우 ②: 자동차가 2번 뒤에 있음 (확률 1/3) → 사회자는 3번을 열 수밖에 없음 → 바꾸면 ✅
    • 경우 ③: 자동차가 3번 뒤에 있음 (확률 1/3) → 사회자는 2번을 열 수밖에 없음 → 바꾸면 ✅
    flowchart TD S["1번 문 선택"] --> A["자동차 1번 뒤<br/>확률 1/3"] S --> B["자동차 2번 뒤<br/>확률 1/3"] S --> C["자동차 3번 뒤<br/>확률 1/3"] A -->|"유지 → 🚗 당첨"| W1["유지 승리"] B -->|"바꾸기 → 🚗 당첨"| W2["바꾸기 승리"] C -->|"바꾸기 → 🚗 당첨"| W3["바꾸기 승리"]

    📌 정리하기: 유지 승률 = 1/3, 바꾸기 승률 = 2/3. 바꾸는 것이 2배 유리합니다!

    이것을 조건부 확률로 표현하면: - P(자동차가 처음 선택한 문 | 사회자가 염소 문을 열었음) = 1/3 - P(자동차가 나머지 문 | 사회자가 염소 문을 열었음) = 2/3

    사회자가 문을 열어주는 행위(조건)가 확률을 재분배한 것입니다.

    🔨 따라하기: 엔트리로 몬티홀 시뮬레이터 만들기¶

    100회 반복 실험으로 바꾸기 vs 유지 승률을 직접 확인해 봅시다.

    Step 1: 변수 준비¶

    엔트리에서 다음 변수를 만드세요.

    • 자동차위치, 내선택, 사회자열기
    • 유지승리횟수, 바꾸기승리횟수, 반복횟수

    Step 2: 핵심 로직 (엔트리 파이썬 모드)¶

    import random

stay_win = 0      # 유지 전략 승리 횟수
switch_win = 0    # 바꾸기 전략 승리 횟수
total = 1000      # 반복 횟수

for i in range(total):
    # 1) 자동차 위치 랜덤 설정 (1, 2, 3번 문)
    car = random.randint(1, 3)

    # 2) 참가자가 문 하나 선택
    my_pick = random.randint(1, 3)

    # 3) 사회자가 염소 문 하나 열기
    #    (참가자가 고른 문도, 자동차 문도 아닌 문)
    doors = [1, 2, 3]
    can_open = [d for d in doors if d != my_pick and d != car]
    host_open = random.choice(can_open)

    # 4) 바꾸기: 남은 문으로 변경
    switch_pick = [d for d in doors if d != my_pick and d != host_open][0]

    # 5) 결과 판정
    if my_pick == car:
        stay_win += 1
    if switch_pick == car:
        switch_win += 1

print(f"유지 전략 승률: {stay_win/total*100:.1f}%")
print(f"바꾸기 전략 승률: {switch_win/total*100:.1f}%")

    Step 3: 실행 결과 확인¶

    유지 전략 승률: 33.2%
바꾸기 전략 승률: 66.8%

    Step 4: 결과 해석¶

    1000번 반복하니 유지는 약 33%, 바꾸기는 약 67%로 수렴합니다. 이론값(1/3과 2/3)과 거의 일치하죠!

    💡 생각해보기: total 값을 10, 100, 10000으로 바꿔 보세요. 횟수가 많아질수록 이론값에 가까워지는 대수의 법칙을 체감할 수 있습니다.

    📝 전체 코드¶

    import random

stay_win = 0
switch_win = 0
total = 1000

for i in range(total):
    car = random.randint(1, 3)
    my_pick = random.randint(1, 3)

    doors = [1, 2, 3]
    can_open = [d for d in doors if d != my_pick and d != car]
    host_open = random.choice(can_open)

    switch_pick = [d for d in doors if d != my_pick and d != host_open][0]

    if my_pick == car:
        stay_win += 1
    if switch_pick == car:
        switch_win += 1

print(f"=== 몬티홀 시뮬레이션 ({total}회) ===")
print(f"유지 전략 승률: {stay_win/total*100:.1f}%")
print(f"바꾸기 전략 승률: {switch_win/total*100:.1f}%")
print(f"바꾸기가 유지보다 {switch_win/max(stay_win,1):.1f}배 유리!")

    ⚠️ 주의할 점¶

    1. 조건의 방향을 헷갈리지 마세요!

    P(A|B)와 P(B|A)는 전혀 다릅니다. "비가 올 때 우산을 가져올 확률"과 "우산을 가져왔을 때 비가 올 확률"은 다르죠. 세로줄( | ) 뒤가 이미 일어난 조건입니다.

    2. 몬티홀의 핵심은 '사회자의 규칙'입니다

    사회자가 무작위로 문을 열었다면(자동차가 나올 수도 있다면) 바꿔도 유리하지 않습니다. 사회자가 반드시 염소 문만 연다는 규칙이 확률을 바꾸는 조건이 됩니다.

    ✅ 점검하기¶

    1. [기본] 빨간 공 3개, 파란 공 2개가 들어 있는 주머니에서 공을 하나 꺼냈더니 빨간 공이었습니다. 다시 넣지 않고 하나를 더 꺼낼 때, 그것이 빨간 공일 확률은?

    정답 확인 처음 빨간 공을 꺼낸 후 남은 공: 빨간 2개 + 파란 2개 = 4개 P(두 번째 빨간 | 첫 번째 빨간) = **2/4 = 1/2** 첫 번째 결과(조건)가 두 번째 확률을 바꾼 것입니다!

    2. [응용] 몬티홀 문제에서 참가자가 1번 문을 골랐고 자동차가 2번 뒤에 있을 때, 사회자가 열 수 있는 문은 몇 번이고 왜 그런가요?

    정답 확인 **3번 문만** 열 수 있습니다. 1번은 참가자가 선택했으므로 열 수 없고, 2번은 자동차가 있으므로 열 수 없습니다. 따라서 사회자에게 선택의 여지가 없으며, 이것이 바로 **바꾸면 반드시 당첨되는 경우**입니다.

    3. [심화·도전] 문이 4개(자동차 1개, 염소 3개)로 늘어났습니다. 참가자가 하나를 고른 뒤 사회자가 염소 문 2개를 열어줍니다. 바꾸기 전략의 승률은 이론적으로 얼마일까요?

    정답 확인 처음 맞힐 확률 = 1/4, 틀릴 확률 = 3/4 사회자가 염소 문 2개를 열면 남은 문은 1개뿐. 바꾸면 처음 틀렸던 3/4의 확률이 그 문에 집중됩니다. **바꾸기 승률 = 3/4 = 75%**, 유지 승률 = 1/4 = 25% 문이 많아질수록 바꾸기 전략이 **더욱 유리**해집니다!

    📌 핵심 요약 - 조건부 확률 P(A|B): 사건 B가 일어났다는 정보 아래에서 A의 확률. 공식은 P(A∩B)/P(B) - 몬티홀 문제: 사회자의 정보(조건) 덕분에 바꾸기 승률 2/3, 유지 승률 1/3 - 새로운 정보(조건)는 확률을 재분배한다 — 이것이 조건부 확률의 본질!
