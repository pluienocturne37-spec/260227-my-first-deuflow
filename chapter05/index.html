    Chapter 05. 식을 접었다 펼쳤다 — 전개와 인수분해 시각화¶

    Part 2 | [1권] Part 2. 공통수학1 — 다항식, 코드로 계산하다

    🎯 이 장에서 배우는 것¶

    • 다항식의 전개와 인수분해가 '펼치기'와 '묶기'라는 반대 과정임을 이해할 수 있다
    • 넓이 모델(사각형 블록)을 활용해 (a+b)² = a² + 2ab + b² 을 시각적으로 확인할 수 있다
    • 전개식의 결과를 코드로 자동 계산하고, 손 계산과 비교할 수 있다

    📚 핵심 개념¶

    개념 1: 전개 — 식을 펼치기 🔓¶

    1. 비유로 시작: 전개는 마치 접힌 우산을 활짝 펴는 것과 같아요. 괄호 안에 숨어 있던 항들이 바깥으로 쫙 드러납니다.

    2. 정확한 정의: 전개(展開) 란 괄호가 있는 곱의 형태를 분배법칙으로 풀어 쓰는 것입니다.

    3. 예시로 확인:

    (a + b)² = (a + b)(a + b) = a² + ab + ba + b² = a² + 2ab + b²

    괄호 하나였던 식이 세 개의 항으로 "펼쳐졌습니다!"

    개념 2: 인수분해 — 식을 묶기 🔒¶

    1. 비유로 시작: 인수분해는 마치 펼쳐진 우산을 다시 접는 것과 같아요. 흩어진 항들 사이에서 공통된 구조를 찾아 다시 괄호로 묶습니다.

    2. 정확한 정의: 인수분해(因數分解) 란 전개의 반대 과정으로, 다항식을 두 개 이상의 곱으로 되돌리는 것입니다.

    3. 예시로 확인:

    a² + 2ab + b² → 이 안에서 (a+b)가 두 번 곱해진 패턴을 발견!

    → (a + b)² 으로 다시 접기 완료!

    💡 알아보기: 전개와 인수분해의 관계

    flowchart LR A["(a + b)²"] -->|"전개 (펼치기)"| B["a² + 2ab + b²"] B -->|"인수분해 (묶기)"| A

    두 과정은 정확히 반대 방향입니다. 전개를 잘하면 인수분해의 결과를 검산할 수 있고, 인수분해를 잘하면 복잡한 식을 간단히 만들 수 있어요.

    📐 넓이 모델로 눈으로 확인하기¶

    (a+b)²이 왜 a² + 2ab + b²인지, 정사각형 넓이로 확인해 봅시다.

    한 변의 길이가 (a + b) 인 정사각형을 그린 뒤, 한 변을 a 부분과 b 부분으로 나누면 네 조각이 생깁니다.

    block-beta columns 2 block:top1["a × a\n= a²"]:1 end block:top2["a × b\n= ab"]:1 end block:bot1["b × a\n= ab"]:1 end block:bot2["b × b\n= b²"]:1 end

    네 조각의 넓이를 모두 더하면:

    a² + ab + ab + b² = a² + 2ab + b² ✅

    이것이 바로 (a+b)² 의 전개 결과입니다!

    🤔 생각해보기: 만약 a = 3, b = 2라면 한 변이 5인 정사각형(넓이 25)이 9 + 6 + 6 + 4 = 25로 딱 맞을까요? 직접 계산해 보세요!

    🔨 따라하기 — 코드로 넓이 모델 계산하기¶

    Step 1: 변수 선언하고 값 입력받기¶

    사용자로부터 a, b 값을 입력받습니다.

    # a, b 값 입력받기
a = int(input("a 값을 입력하세요: "))
b = int(input("b 값을 입력하세요: "))
print(f"a = {a}, b = {b}")

    실행 결과: 

    a 값을 입력하세요: 3
b 값을 입력하세요: 2
a = 3, b = 2

    Step 2: 네 조각의 넓이 각각 계산하기¶

    정사각형을 나눈 네 조각의 넓이를 변수에 저장합니다.

    # 네 조각 넓이 계산
piece1 = a * a      # 왼쪽 위: a²
piece2 = a * b      # 오른쪽 위: ab
piece3 = b * a      # 왼쪽 아래: ba
piece4 = b * b      # 오른쪽 아래: b²

print(f"조각1(a²)  = {piece1}")
print(f"조각2(ab)  = {piece2}")
print(f"조각3(ba)  = {piece3}")
print(f"조각4(b²)  = {piece4}")

    실행 결과: 

    조각1(a²)  = 9
조각2(ab)  = 6
조각3(ba)  = 6
조각4(b²)  = 4

    Step 3: 전개 결과와 원래 식 비교하기¶

    네 조각을 더한 값(전개식)과 (a+b)²을 직접 계산한 값이 같은지 확인합니다.

    # 전개식: a² + 2ab + b²
expand_result = piece1 + piece2 + piece3 + piece4

# 원래 식: (a+b)²
original = (a + b) ** 2

print(f"\n[전개식] a² + 2ab + b² = {piece1} + {piece2} + {piece3} + {piece4} = {expand_result}")
print(f"[원래식] (a+b)² = ({a}+{b})² = {original}")

# 검증
if expand_result == original:
    print("✅ 일치! 전개가 정확합니다!")
else:
    print("❌ 불일치! 다시 확인해보세요.")

    실행 결과: 

    [전개식] a² + 2ab + b² = 9 + 6 + 6 + 4 = 25
[원래식] (a+b)² = (3+2)² = 25
✅ 일치! 전개가 정확합니다!

    Step 4: 다양한 값으로 반복 실험하기¶

    여러 값을 한 번에 테스트하는 코드를 작성합니다.

    # 여러 (a, b) 쌍을 한꺼번에 테스트
test_cases = [(1, 1), (3, 2), (5, 4), (10, 7)]

for a, b in test_cases:
    expand = a**2 + 2*a*b + b**2
    direct = (a + b) ** 2
    mark = "✅" if expand == direct else "❌"
    print(f"a={a}, b={b} → 전개: {expand}, (a+b)²: {direct} {mark}")

    실행 결과: 

    a=1, b=1 → 전개: 4, (a+b)²: 4 ✅
a=3, b=2 → 전개: 25, (a+b)²: 25 ✅
a=5, b=4 → 전개: 81, (a+b)²: 81 ✅
a=10, b=7 → 전개: 289, (a+b)²: 289 ✅

    어떤 숫자를 넣어도 항상 일치합니다. 이것이 공식의 힘이에요! 🎉

    📝 전체 코드¶

    # === (a+b)² 전개와 넓이 모델 시각화 프로그램 ===

# Step 1: 값 입력
a = int(input("a 값을 입력하세요: "))
b = int(input("b 값을 입력하세요: "))
print(f"a = {a}, b = {b}\n")

# Step 2: 네 조각 넓이 계산
piece1 = a * a      # a²
piece2 = a * b      # ab
piece3 = b * a      # ba (= ab)
piece4 = b * b      # b²

print("[ 넓이 모델 — 네 조각 ]")
print(f"  왼쪽 위 (a×a) = {piece1}")
print(f"  오른쪽 위 (a×b) = {piece2}")
print(f"  왼쪽 아래 (b×a) = {piece3}")
print(f"  오른쪽 아래 (b×b) = {piece4}\n")

# Step 3: 결과 비교
expand_result = piece1 + piece2 + piece3 + piece4
original = (a + b) ** 2

print(f"[전개식] a² + 2ab + b² = {expand_result}")
print(f"[원래식] (a+b)² = {original}")

if expand_result == original:
    print("✅ 일치! 전개가 정확합니다!")
else:
    print("❌ 불일치! 다시 확인해보세요.")

# Step 4: 추가 실험
print("\n[ 추가 실험 ]")
test_cases = [(1, 1), (3, 2), (5, 4), (10, 7)]
for a, b in test_cases:
    expand = a**2 + 2*a*b + b**2
    direct = (a + b) ** 2
    mark = "✅" if expand == direct else "❌"
    print(f"  a={a}, b={b} → 전개: {expand}, (a+b)²: {direct} {mark}")

    ⚠️ 주의할 점¶

    1. (a+b)²은 a² + b²이 아닙니다!

    가장 흔한 실수입니다. 넓이 모델을 떠올려 보세요 — 가운데 2ab 조각 두 개를 빠뜨리면 정사각형이 완성되지 않습니다. 반드시 a² + 2ab + b² 세 항이 필요합니다.

    2. 전개와 인수분해는 방향이 반대!

    • 괄호 → 풀어쓰기 = 전개
    • 풀어진 항 → 괄호로 묶기 = 인수분해

    코드에서 검증할 때, 두 방향 모두 계산해서 값이 같은지 비교하는 습관을 들이세요.

    ✅ 점검하기¶

    1. (기본) (a+b)²을 전개한 결과는 무엇인가요?

    정답 확인 **a² + 2ab + b²** 넓이 모델에서 네 조각(a², ab, ab, b²)을 합친 결과입니다.

    2. (응용) (a+b)(a−b)를 전개하면 어떻게 되나요? 아래 코드의 빈칸을 채워 직접 확인해 보세요.

    a, b = 5, 3
result1 = (a + b) * (a - b)
result2 = a**2 - ____    # 빈칸을 채우세요
print(result1, result2)
    정답 확인 빈칸: **b\*\*2** (a+b)(a−b) = **a² − b²** (합차 공식) a=5, b=3이면: 8 × 2 = 16, 25 − 9 = 16으로 일치합니다.

    3. (심화) (a+b+c)²을 넓이 모델로 생각하면 조각이 몇 개가 될까요? 전개 결과를 써 보세요.

    정답 확인 한 변을 a, b, c 세 부분으로 나누면 **3×3 = 9조각**이 됩니다. **(a+b+c)² = a² + b² + c² + 2ab + 2bc + 2ca** 제곱 항 3개 + 교차 항 3개 = 총 6개의 항으로 전개됩니다.

    📋 정리하기

    • 전개 = 괄호를 풀어 펼치기 (곱 → 합)
    • 인수분해 = 공통 구조를 찾아 묶기 (합 → 곱)
    • 넓이 모델로 보면 전개 공식이 왜 성립하는지 눈으로 확인 가능
    • 코드로 여러 값을 넣어 보면 공식이 항상 성립함을 실험적으로 검증 가능
