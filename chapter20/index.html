    Chapter 20. 확률의 덧셈과 곱셈 — 콤보 확률 계산기¶

    Part 7. 공통수학2 — 확률, 랜덤의 세계를 지배하다

    🎯 이 장에서 배우는 것¶

    • 배반사건의 덧셈 법칙과 독립사건의 곱셈 법칙을 구분할 수 있다
    • 게임에서 연속 크리티컬이 터질 확률을 곱셈 법칙으로 계산할 수 있다
    • 엔트리(파이썬)에서 연속 이벤트 확률을 시뮬레이션하는 프로그램을 만들 수 있다

    📚 핵심 개념¶

    🎮 시작하기 전에 — 질문 하나!¶

    RPG 게임에서 크리티컬 확률이 25%입니다. 공격 버튼을 3번 연속 눌렀을 때, 3연속 크리티컬이 터질 확률은 얼마일까요?

    "25% × 3 = 75%?" 🤔 아닙니다! 이건 흔한 오해예요. 정답을 알려면 덧셈 법칙과 곱셈 법칙을 구분해야 합니다.

    개념 1: 덧셈 법칙 (OR — "이것 또는 저것")¶

    비유로 시작: 덧셈 법칙은 마치 뷔페에서 메인 요리를 고르는 것과 같아요. 스테이크 또는 파스타 또는 초밥 — 이 중 하나를 고를 확률은 각각의 확률을 더합니다.

    정확한 정의: 두 사건 A와 B가 동시에 일어날 수 없을 때(배반사건), 둘 중 하나가 일어날 확률은

    P(A 또는 B) = P(A) + P(B)

    예시로 확인: 주사위를 던져서 1이 나오거나 6이 나올 확률은?

    • P(1) = 1/6, P(6) = 1/6
    • 1과 6은 동시에 나올 수 없으므로 → 배반사건
    • P(1 또는 6) = 1/6 + 1/6 = 2/6 = 1/3

    💡 알아보기: 배반사건이란 "동시에 일어날 수 없는 사건"입니다. 주사위 한 번 던지기에서 1과 6이 동시에 나올 수는 없죠!

    개념 2: 곱셈 법칙 (AND — "이것 그리고 저것")¶

    비유로 시작: 곱셈 법칙은 마치 자물쇠 비밀번호를 맞추는 것과 같아요. 첫 번째 숫자도 맞고, 두 번째 숫자도 맞고, 세 번째 숫자도 맞아야 열립니다. 각 단계를 모두 통과해야 하니까 확률을 곱합니다.

    정확한 정의: 두 사건 A와 B가 서로 영향을 주지 않을 때(독립사건), 둘 다 일어날 확률은

    P(A 그리고 B) = P(A) × P(B)

    예시로 확인: 크리티컬 확률 25%일 때, 3연속 크리티컬 확률은?

    • 각 공격은 서로 영향 없음 → 독립사건
    • P(3연속) = 0.25 × 0.25 × 0.25 = 0.015625 ≈ 약 1.6%

    💡 생각해보기: 25%가 3번이면 75%가 아니라 약 1.6%! 독립사건을 "곱하면" 확률이 급격히 작아집니다. 이래서 연속 크리티컬이 그토록 짜릿한 거예요! 🎉

    한눈에 비교¶

    flowchart LR Q["두 사건의 관계는?"] --> OR["OR: 둘 중 하나만\n일어나면 OK"] Q --> AND["AND: 둘 다\n일어나야 OK"] OR --> ADD["덧셈 법칙\nP(A) + P(B)\n배반사건"] AND --> MUL["곱셈 법칙\nP(A) × P(B)\n독립사건"]

    🔑 정리하기: "또는"은 더하기, "그리고"는 곱하기!

    🔨 따라하기 — 전투 크리티컬 시뮬레이터¶

    크리티컬 확률 25%로 공격을 반복하며, 연속 크리티컬 최대 횟수를 기록하는 프로그램을 만들어 봅시다.

    Step 1: 한 번 공격 — 크리티컬 판정¶

    import random

# 크리티컬 확률 25%
def attack():
    roll = random.random()  # 0.0 ~ 1.0 사이 랜덤 숫자
    if roll < 0.25:
        return True   # 크리티컬!
    else:
        return False   # 일반 공격

    실행 결과 (예시): 

    True  → 크리티컬 발생!

    Step 2: 연속 크리티컬 카운터 만들기¶

    def battle(num_attacks):
    streak = 0        # 현재 연속 크리티컬 수
    max_streak = 0    # 최대 연속 크리티컬 수

    for i in range(num_attacks):
        if attack():
            streak += 1
            if streak > max_streak:
                max_streak = streak
            print(f"  공격 {i+1}: 💥 크리티컬! (연속 {streak}회)")
        else:
            streak = 0  # 연속 끊김! 리셋
            print(f"  공격 {i+1}: ⚔️ 일반 공격")

    return max_streak

    Step 3: 10번 공격 실행¶

    print("=== 전투 시작! (크리티컬 확률 25%) ===")
result = battle(10)
print(f"\n🏆 최대 연속 크리티컬: {result}회")

    Step 4: 이론값과 시뮬레이션 비교¶

    1,000번 전투를 반복해서 "3연속 크리티컬이 한 번이라도 나온 비율"을 확인합니다.

    def has_triple_critical(num_attacks):
    """한 번의 전투에서 3연속 크리티컬이 나왔는지 확인"""
    streak = 0
    for _ in range(num_attacks):
        if attack():
            streak += 1
            if streak >= 3:
                return True
        else:
            streak = 0
    return False

# 1,000번 전투 시뮬레이션
trials = 1000
attacks_per_battle = 3  # 딱 3번 공격
count = 0

for _ in range(trials):
    if has_triple_critical(attacks_per_battle):
        count += 1

print(f"=== 3번 공격 중 3연속 크리티컬 ===")
print(f"이론값: {0.25**3:.4f} ({0.25**3*100:.2f}%)")
print(f"시뮬레이션: {count/trials:.4f} ({count/trials*100:.2f}%)")

    실행 결과 (예시): 

    === 3번 공격 중 3연속 크리티컬 ===
이론값: 0.0156 (1.56%)
시뮬레이션: 0.0140 (1.40%)

    💡 시뮬레이션 횟수를 늘릴수록 이론값에 가까워집니다!

    📝 전체 코드¶

    import random

# --- 크리티컬 판정 ---
def attack():
    return random.random() < 0.25  # 크리티컬 확률 25%

# --- 한 번의 전투 (연속 크리티컬 추적) ---
def battle(num_attacks):
    streak = 0
    max_streak = 0
    for i in range(num_attacks):
        if attack():
            streak += 1
            if streak > max_streak:
                max_streak = streak
            print(f"  공격 {i+1}: 💥 크리티컬! (연속 {streak}회)")
        else:
            streak = 0
            print(f"  공격 {i+1}: ⚔️ 일반 공격")
    return max_streak

# --- 3연속 크리티컬 검사 ---
def has_triple_critical(num_attacks):
    streak = 0
    for _ in range(num_attacks):
        if attack():
            streak += 1
            if streak >= 3:
                return True
        else:
            streak = 0
    return False

# === 실행 ===
print("=== 전투 시작! (크리티컬 확률 25%) ===")
result = battle(10)
print(f"\n🏆 최대 연속 크리티컬: {result}회")

# === 시뮬레이션 검증 ===
print("\n=== 시뮬레이션 검증 (1,000회) ===")
trials = 1000
count = sum(1 for _ in range(trials) if has_triple_critical(3))
print(f"이론값: {0.25**3*100:.2f}%")
print(f"시뮬레이션: {count/trials*100:.2f}%")

    ⚠️ 주의할 점¶

    1. 덧셈 법칙은 "배반사건"일 때만 단순히 더할 수 있습니다!

    배반이 아닌 경우(예: "짝수 또는 4의 배수"), 겹치는 부분을 빼야 합니다. → P(A 또는 B) = P(A) + P(B) − P(A 그리고 B)

    2. "확률이 낮다 = 절대 안 일어난다"가 아닙니다!

    3연속 크리티컬 확률 1.6%는 낮지만, 100번 전투하면 1~2번은 일어날 수 있습니다. 시뮬레이션이 이것을 눈으로 보여줍니다.

    ✅ 점검하기¶

    1. (기본) 동전 2개를 동시에 던질 때, 둘 다 앞면이 나올 확률은?

    정답 확인 각 동전은 독립사건이고 앞면 확률은 1/2입니다. **P(둘 다 앞면) = 1/2 × 1/2 = 1/4 (25%)** → 곱셈 법칙 적용! "그리고"이므로 곱합니다.

    2. (응용) 주사위를 한 번 던져 "1 또는 2 또는 3"이 나올 확률은? 어떤 법칙을 쓰나요?

    정답 확인 1, 2, 3은 동시에 나올 수 없는 **배반사건**입니다. **P = 1/6 + 1/6 + 1/6 = 3/6 = 1/2 (50%)** → 덧셈 법칙 적용! "또는"이므로 더합니다.

    3. (도전) 크리티컬 확률 25%일 때, 5연속 크리티컬이 터질 확률을 계산하고, 코드의 has_triple_critical 함수를 수정하여 시뮬레이션으로 검증해 보세요.

    정답 확인 **이론값**: 0.25⁵ = 0.0009765625 ≈ **약 0.098% (1,000번 중 약 1번)** 코드 수정: `if streak >= 3`을 `if streak >= 5`로, `has_triple_critical(3)`을 `has_triple_critical(5)`로 바꾸면 됩니다. 시뮬레이션 횟수는 10,000회 이상으로 늘려야 의미 있는 결과를 볼 수 있습니다.

    🔑 핵심 요약 - "또는"(OR) → 확률을 더한다 (배반사건일 때) - "그리고"(AND) → 확률을 곱한다 (독립사건일 때) - 독립사건을 곱하면 확률은 급격히 작아진다 - 이론으로 계산하고, 시뮬레이션으로 검증하는 것이 확률 공부의 핵심!
