    Chapter 19. 드롭률의 진실 — 확률의 기본과 게임 뽑기¶

    Part 7. 공통수학2 — 확률, 랜덤의 세계를 지배하다

    🎯 이 장에서 배우는 것¶

    • 확률의 정의(유리한 경우의 수 ÷ 전체 경우의 수)를 설명할 수 있다
    • 게임 아이템 드롭률을 확률로 해석하고, "확률의 함정"을 이해할 수 있다
    • 엔트리(Python)로 가챠 시뮬레이터를 만들어 확률을 직접 체감할 수 있다

    📚 핵심 개념¶

    개념 1: 확률이란?¶

    💡 생각해보기: 모바일 게임에서 "SSR 등급 확률 3%"라고 적혀 있습니다. 그러면 33번 뽑으면 반드시 SSR이 나올까요?

    정답은 "아니요" 입니다. 이 오해를 풀려면 확률의 정의를 정확히 알아야 합니다.

    1) 비유로 시작

    확률은 마치 날씨 예보와 같아요. "비 올 확률 70%"라고 해서 10일 중 정확히 7일 비가 오는 건 아닙니다. 오랫동안 모아보면 대략 그 비율에 가까워진다는 뜻이죠.

    2) 정확한 정의

    $$P(A) = \frac{\text{사건 A가 일어나는 경우의 수}}{\text{모든 경우의 수}}$$

    • P(A): 사건 A가 일어날 확률
    • 확률의 범위: 0 ≤ P(A) ≤ 1 (0%~100%)

    3) 예시로 확인

    주사위 하나를 던져서 3의 배수가 나올 확률은?

    • 모든 경우의 수: {1, 2, 3, 4, 5, 6} → 6가지
    • 3의 배수: {3, 6} → 2가지
    • 확률: 2/6 = 1/3 ≈ 33.3%

    개념 2: 대수의 법칙 — 반복할수록 진실에 가까워진다¶

    1) 비유로 시작

    동전을 5번 던지면 앞면이 5번 연속 나올 수도 있어요. 하지만 50,000번 던지면? 앞면 비율은 거의 정확히 50%에 가까워집니다. 이것이 대수의 법칙입니다.

    2) 정확한 정의

    대수의 법칙(큰 수의 법칙): 시행 횟수를 충분히 늘리면, 실제 결과의 비율이 이론적 확률에 점점 가까워진다.

    3) 게임에 적용하면?

    • SSR 확률 3% → 33번 뽑아도 SSR 0개일 확률이 약 36%나 됩니다!
    • 하지만 10,000번 뽑으면 SSR 비율은 거의 3%에 수렴합니다
    graph LR A["🎲 적은 시행<br/>5~30회"] -->|"결과 들쭉날쭉"| B["실제 비율 ≠ 이론 확률"] C["🎲 많은 시행<br/>1,000회 이상"] -->|"대수의 법칙"| D["실제 비율 ≈ 이론 확률"]

    📌 알아보기: 33번 뽑아서 SSR이 최소 1개 나올 확률을 계산해봅시다. - 1회에 SSR이 안 나올 확률 = 0.97 - 33번 연속 안 나올 확률 = 0.97³³ ≈ 0.364 (36.4%) - 즉, 1개 이상 나올 확률 = 1 − 0.364 = 63.6% (100%가 아닙니다!)

    🔨 따라하기: 가챠 시뮬레이터 만들기¶

    게임의 뽑기 시스템을 직접 코드로 만들어서 확률을 체감해봅시다.

    등급별 확률 설정: - 🌟 SSR: 3% - ⭐ SR: 17% - 💎 R: 80%

    Step 1: 1회 뽑기 함수 만들기¶

    import random

def gacha():
    roll = random.randint(1, 100)  # 1~100 사이 랜덤 숫자
    if roll <= 3:          # 1~3: SSR (3%)
        return "SSR"
    elif roll <= 20:       # 4~20: SR (17%)
        return "SR"
    else:                  # 21~100: R (80%)
        return "R"

# 테스트: 1회 뽑기
result = gacha()
print(f"뽑기 결과: {result}")

    실행 결과 (매번 다름): 

    뽑기 결과: R

    Step 2: 여러 번 뽑고 결과 집계하기¶

    def simulate(times):
    counts = {"SSR": 0, "SR": 0, "R": 0}
    for i in range(times):
        result = gacha()
        counts[result] += 1
    return counts

# 10회 뽑기
result_10 = simulate(10)
print(f"10회 결과: {result_10}")

    실행 결과 (예시): 

    10회 결과: {'SSR': 0, 'SR': 2, 'R': 8}

    Step 3: 비율 계산 및 이론 확률과 비교하기¶

    def simulate_and_compare(times):
    counts = simulate(times)
    print(f"\n=== {times}회 뽑기 결과 ===")
    for grade in ["SSR", "SR", "R"]:
        actual = counts[grade] / times * 100
        print(f"{grade}: {counts[grade]}개 ({actual:.1f}%)")

# 적은 횟수 vs 많은 횟수 비교
simulate_and_compare(10)
simulate_and_compare(100)
simulate_and_compare(10000)

    Step 4: SSR 나올 때까지 몇 번 걸리는지 실험¶

    def until_ssr():
    """SSR이 나올 때까지 뽑기 반복"""
    count = 0
    while True:
        count += 1
        if gacha() == "SSR":
            return count

# 10명의 플레이어가 SSR 뽑을 때까지
print("=== SSR까지 걸린 횟수 ===")
for player in range(1, 11):
    tries = until_ssr()
    print(f"플레이어 {player}: {tries}번 만에 SSR!")

    누군가는 1번 만에, 누군가는 100번이 넘어도… 이것이 확률의 현실입니다. 확률 3%의 평균 기댓값은 약 33회이지만, 개인 편차는 엄청나게 크죠.

    📝 전체 코드¶

    import random

# --- 1회 뽑기 함수 ---
def gacha():
    roll = random.randint(1, 100)
    if roll <= 3:
        return "SSR"
    elif roll <= 20:
        return "SR"
    else:
        return "R"

# --- 여러 번 뽑기 시뮬레이션 ---
def simulate(times):
    counts = {"SSR": 0, "SR": 0, "R": 0}
    for i in range(times):
        counts[gacha()] += 1
    return counts

# --- 결과 출력 및 비교 ---
def simulate_and_compare(times):
    counts = simulate(times)
    theory = {"SSR": 3.0, "SR": 17.0, "R": 80.0}
    print(f"\n=== {times}회 뽑기 결과 ===")
    for grade in ["SSR", "SR", "R"]:
        actual = counts[grade] / times * 100
        diff = abs(actual - theory[grade])
        print(f"{grade}: {counts[grade]}개 (실제 {actual:.1f}% / 이론 {theory[grade]}% / 차이 {diff:.1f}%)")

# --- SSR 나올 때까지 ---
def until_ssr():
    count = 0
    while True:
        count += 1
        if gacha() == "SSR":
            return count

# 실행
simulate_and_compare(10)
simulate_and_compare(100)
simulate_and_compare(10000)

print("\n=== SSR까지 걸린 횟수 (5명) ===")
for p in range(1, 6):
    print(f"플레이어 {p}: {until_ssr()}번")

    ⚠️ 주의할 점¶

    1. "확률 3%니까 33번이면 확정"은 틀린 생각!

    각 뽑기는 독립 시행입니다. 이전에 32번 꽝이 나왔다고 33번째에 SSR이 나올 확률이 올라가지 않습니다. 매번 3%는 3%입니다. (이것을 도박사의 오류라고 합니다.)

    2. 적은 횟수에서는 확률이 안 맞는 게 정상!

    10번 뽑아서 SSR이 0개여도 "버그"가 아닙니다. 대수의 법칙은 충분히 많이 반복해야 작동합니다.

    ✅ 점검하기¶

    기본 문제 1. 주사위 하나를 던질 때, 짝수가 나올 확률은?

    정답 확인 짝수 = {2, 4, 6} → 3가지, 전체 = 6가지 **P = 3/6 = 1/2 = 50%**

    기본 문제 2. "드롭률 5%인 아이템을 20번 잡았는데 하나도 안 나왔어요. 이 게임 확률 조작이에요!" — 이 주장이 왜 틀렸는지 설명하세요.

    정답 확인 20번 연속으로 안 나올 확률 = 0.95²⁰ ≈ **35.8%** 입니다. 약 3명 중 1명은 20번 안에 하나도 못 얻는 것이 **수학적으로 정상**입니다. 적은 시행에서는 이론 확률과 실제 결과가 크게 다를 수 있으며, 이는 대수의 법칙에 의해 시행 횟수가 늘어야 수렴합니다.

    도전 문제 3. 위 코드를 실행하여 100회 뽑기를 5번 반복해보세요. 매번 SSR 비율이 다른 이유를 대수의 법칙으로 설명하세요.

    정답 확인 100회는 대수의 법칙이 충분히 작동할 만큼 큰 수가 아닙니다. 100회 시행에서 SSR 비율은 0%~8% 등 매번 다를 수 있습니다. 그러나 10,000회, 100,000회로 늘리면 SSR 비율이 **3%에 매우 가까워지는 것**을 확인할 수 있습니다. 이것이 "시행을 충분히 반복하면 실제 비율이 이론 확률에 수렴한다"는 대수의 법칙입니다.

    📌 정리하기 - 확률 = 유리한 경우의 수 ÷ 전체 경우의 수 - 확률 3%가 "33번이면 확정"을 의미하지 않는다 - 대수의 법칙: 많이 반복할수록 실제 비율 → 이론 확률에 수렴 - 각 시행은 독립적 → 이전 결과가 다음 결과에 영향 없음
