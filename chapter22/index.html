    데이터로 말하기 — 평균·분산·표준편차 시각화¶

    Part 8. 공통수학2 — 통계, AI의 눈으로 세상을 읽다

    🎯 이 장에서 배우는 것¶

    • 평균·분산·표준편차의 의미를 '대표값'과 '흩어짐 정도'로 설명할 수 있다
    • 같은 평균이라도 분산이 다르면 데이터의 성격이 완전히 달라짐을 체감할 수 있다
    • 엔트리(파이썬)에서 데이터를 입력하면 평균·표준편차를 자동 계산하고 시각화하는 프로그램을 만들 수 있다

    📚 핵심 개념¶

    🤔 생각해보기: 누구를 팀원으로 뽑겠어?¶

    프로 게이머 두 명이 있습니다. 최근 5경기 킬 수를 볼까요?

    • 선수 A: 7, 8, 7, 8, 10 → 평균 8킬
    • 선수 B: 2, 14, 3, 12, 9 → 평균 8킬

    평균은 똑같이 8킬인데, 느낌이 완전히 다르지 않나요? A는 안정적이고, B는 들쭉날쭉합니다. 평균만 보면 두 사람이 같아 보이지만, "흩어짐 정도"를 보면 전혀 다른 선수입니다. 이 차이를 숫자로 표현하는 것이 바로 분산과 표준편차입니다.

    개념 1: 평균 — 데이터의 무게중심¶

    📌 비유: 평균은 시소의 받침점과 같아요. 모든 데이터를 시소에 올렸을 때, 정확히 균형이 잡히는 지점입니다.

    정확한 정의

    평균(mean) = 모든 데이터 값의 합 ÷ 데이터 개수

    $$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$$

    예시로 확인: 선수 A의 평균

    (7 + 8 + 7 + 8 + 10) ÷ 5 = 40 ÷ 5 = 8

    💡 알아보기: 평균은 "대표값"입니다. 하지만 대표값 하나만으로는 데이터의 전체 모습을 알 수 없습니다. 마치 키 평균이 170cm인 팀이 전원 170cm일 수도 있고, 150cm와 190cm가 섞여 있을 수도 있는 것처럼요.

    개념 2: 분산과 표준편차 — 흩어짐의 크기¶

    📌 비유: 분산은 교실에서 학생들이 중심점(평균)으로부터 얼마나 멀리 흩어져 앉아 있는지를 측정한 값이에요. 모여 앉으면 분산이 작고, 넓게 퍼지면 분산이 큽니다.

    정확한 정의

    • 편차 = 각 데이터 값 − 평균
    • 분산(variance) = 편차의 제곱의 평균

    $$\sigma^2 = \frac{(x_1-\bar{x})^2 + (x_2-\bar{x})^2 + \cdots + (x_n-\bar{x})^2}{n}$$

    • 표준편차(standard deviation) = 분산의 제곱근

    $$\sigma = \sqrt{\text{분산}}$$

    💡 알아보기: 왜 편차를 그냥 합하지 않고 제곱할까요? 편차를 그대로 더하면 양수와 음수가 상쇄되어 합이 0이 됩니다. 제곱하면 모두 양수가 되어 흩어짐 크기를 정확히 측정할 수 있습니다.

    예시로 확인 — 선수 A vs 선수 B

    flowchart LR subgraph 선수A ["선수 A (안정적)"] A1["편차: -1, 0, -1, 0, 2"] A2["편차²: 1, 0, 1, 0, 4"] A3["분산 = 6÷5 = 1.2"] A4["표준편차 ≈ 1.10"] A1 --> A2 --> A3 --> A4 end subgraph 선수B ["선수 B (들쭉날쭉)"] B1["편차: -6, 6, -5, 4, 1"] B2["편차²: 36, 36, 25, 16, 1"] B3["분산 = 114÷5 = 22.8"] B4["표준편차 ≈ 4.77"] B1 --> B2 --> B3 --> B4 end

    선수 A의 표준편차는 약 1.10, 선수 B는 약 4.77. B가 A보다 4배 이상 흩어져 있습니다!

    🎯 정리하기: 표준편차가 작으면 → 데이터가 평균 근처에 몰려 있다 (안정적). 표준편차가 크면 → 데이터가 평균에서 멀리 퍼져 있다 (불안정).

    🔨 따라하기: 평균·표준편차 자동 계산 & 시각화¶

    Step 1: 데이터 입력과 평균 계산¶

    # 데이터 입력
data = [7, 8, 7, 8, 10]  # 선수 A의 킬 수

# 평균 계산
n = len(data)
total = sum(data)
mean = total / n
print(f"데이터: {data}")
print(f"평균: {mean}")

    실행 결과: 

    데이터: [7, 8, 7, 8, 10]
평균: 8.0

    Step 2: 편차와 분산 구하기¶

    # 편차 리스트 만들기
deviations = []
for x in data:
    deviations.append(x - mean)
print(f"편차: {deviations}")

# 분산 계산 (편차 제곱의 평균)
squared_sum = 0
for d in deviations:
    squared_sum += d ** 2
variance = squared_sum / n
print(f"분산: {variance}")

    실행 결과: 

    편차: [-1.0, 0.0, -1.0, 0.0, 2.0]
분산: 1.2

    Step 3: 표준편차 구하기¶

    # 표준편차 = 분산의 제곱근
std_dev = variance ** 0.5
print(f"표준편차: {round(std_dev, 2)}")

    실행 결과: 

    표준편차: 1.1

    Step 4: 막대그래프로 시각화하기¶

    import matplotlib.pyplot as plt

# 두 선수 데이터
data_a = [7, 8, 7, 8, 10]
data_b = [2, 14, 3, 12, 9]
games = ["1경기", "2경기", "3경기", "4경기", "5경기"]

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

# 선수 A 그래프
axes[0].bar(games, data_a, color="skyblue")
axes[0].axhline(y=8, color="red", linestyle="--", label="평균=8")
axes[0].set_title("선수 A (표준편차 ≈ 1.10)")
axes[0].set_ylim(0, 16)
axes[0].legend()

# 선수 B 그래프
axes[1].bar(games, data_b, color="salmon")
axes[1].axhline(y=8, color="red", linestyle="--", label="평균=8")
axes[1].set_title("선수 B (표준편차 ≈ 4.77)")
axes[1].set_ylim(0, 16)
axes[1].legend()

plt.tight_layout()
plt.savefig("comparison.png")
plt.show()

    실행 결과: 두 개의 막대그래프가 나란히 나타납니다. 선수 A는 막대 높이가 빨간 점선(평균) 근처에 모여 있고, 선수 B는 막대 높이가 위아래로 크게 흩어져 있는 것이 한눈에 보입니다.

    📝 전체 코드¶

    import matplotlib.pyplot as plt

def calc_stats(data):
    """평균, 분산, 표준편차를 계산하는 함수"""
    n = len(data)
    mean = sum(data) / n
    variance = sum((x - mean) ** 2 for x in data) / n
    std_dev = variance ** 0.5
    return round(mean, 2), round(variance, 2), round(std_dev, 2)

# --- 데이터 준비 ---
data_a = [7, 8, 7, 8, 10]
data_b = [2, 14, 3, 12, 9]
games = ["1경기", "2경기", "3경기", "4경기", "5경기"]

# --- 통계 계산 ---
mean_a, var_a, std_a = calc_stats(data_a)
mean_b, var_b, std_b = calc_stats(data_b)

print(f"선수 A → 평균: {mean_a}, 분산: {var_a}, 표준편차: {std_a}")
print(f"선수 B → 평균: {mean_b}, 분산: {var_b}, 표준편차: {std_b}")

# --- 시각화 ---
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].bar(games, data_a, color="skyblue")
axes[0].axhline(y=mean_a, color="red", linestyle="--", label=f"평균={mean_a}")
axes[0].set_title(f"선수 A (std={std_a})")
axes[0].set_ylim(0, 16)
axes[0].legend()

axes[1].bar(games, data_b, color="salmon")
axes[1].axhline(y=mean_b, color="red", linestyle="--", label=f"평균={mean_b}")
axes[1].set_title(f"선수 B (std={std_b})")
axes[1].set_ylim(0, 16)
axes[1].legend()

plt.tight_layout()
plt.savefig("comparison.png")
plt.show()

    실행 결과: 

    선수 A → 평균: 8.0, 분산: 1.2, 표준편차: 1.1
선수 B → 평균: 8.0, 분산: 22.8, 표준편차: 4.77

    ⚠️ 주의할 점¶

    1. 편차의 합은 항상 0이다! 편차를 그냥 더하면 양수와 음수가 상쇄되어 반드시 0이 됩니다. 그래서 제곱을 해야 합니다. "편차의 합 = 0"을 분산이라고 착각하지 마세요!

    2. 표준편차의 단위는 원래 데이터와 같다 분산은 단위가 "킬²"처럼 제곱이 붙어서 해석이 어렵습니다. 표준편차는 제곱근을 씌우므로 원래 단위(킬)와 같아져 직관적으로 비교할 수 있습니다. 실생활에서 표준편차를 더 자주 쓰는 이유입니다.

    ✅ 점검하기¶

    기본 문제: 데이터 {3, 5, 7}의 평균, 분산, 표준편차를 구하세요.

    정답 확인 - 평균 = (3+5+7) ÷ 3 = **5** - 편차: -2, 0, 2 - 편차²: 4, 0, 4 - 분산 = (4+0+4) ÷ 3 = **8/3 ≈ 2.67** - 표준편차 = √(8/3) ≈ **1.63**

    응용 문제: 데이터 {10, 10, 10, 10}의 표준편차는 얼마일까요? 그 이유는?

    정답 확인 표준편차 = **0**. 모든 값이 평균과 같으므로 편차가 전부 0이고, 흩어짐이 전혀 없기 때문입니다.

    도전 문제: 수학 시험에서 A반 점수 {60, 70, 80, 90, 100}과 B반 점수 {76, 78, 80, 82, 84}의 평균은 둘 다 80점입니다. 위 전체 코드를 수정하여 두 반의 표준편차를 구하고, 어느 반이 더 고르게 공부했는지 판단해보세요.

    정답 확인 - A반 분산 = 200, 표준편차 ≈ **14.14** - B반 분산 = 8, 표준편차 ≈ **2.83** - B반이 표준편차가 훨씬 작으므로 **B반이 더 고르게** 공부한 것입니다. 코드에서 `data_a = [60,70,80,90,100]`, `data_b = [76,78,80,82,84]`로 바꾸면 됩니다!

    🎯 핵심 개념 요약 - 평균: 데이터의 대표값(무게중심) - 분산: 편차 제곱의 평균 → 흩어짐의 크기 - 표준편차: 분산의 제곱근 → 원래 단위로 해석 가능 - 평균이 같아도 표준편차가 다르면 데이터의 성격은 완전히 다르다!
