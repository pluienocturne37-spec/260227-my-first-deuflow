    역·이·대우 탐정 — 조건문 추리 게임¶

    Part 5. 공통수학2 — 집합과 명제, 데이터를 분류하다 | 15차시

    🎯 이 장에서 배우는 것¶

    • 명제의 역·이·대우의 관계를 구분하여 설명할 수 있다
    • 대우의 참·거짓이 원래 명제와 같음을 예시로 확인할 수 있다
    • 엔트리에서 추리 게임을 만들어 대우 관계를 활용한 논리 추론을 체험할 수 있다

    📚 핵심 개념¶

    🕵️ 탐정의 추리, 그것은 대우!¶

    생각해보기: 탐정 드라마의 한 장면을 떠올려 보세요.

    "범인이 장갑을 꼈다면, 지문이 남지 않는다."

    현장에서 지문이 발견되었습니다. 탐정은 즉시 말합니다. "그렇다면 이 사람은 장갑을 끼지 않았군!"

    이 추리가 바로 대우입니다. 탐정은 수학을 모르는 것 같지만, 사실 대우 명제를 매 순간 사용하고 있어요! 🔍

    개념 1: 역·이·대우란?¶

    원래 명제가 "p이면 q이다" (p → q)일 때, 세 가지 새로운 명제를 만들 수 있습니다.

    비유: 명제는 마치 화살표가 있는 길과 같아요. 화살표의 방향을 바꾸거나, 출발지와 도착지에 "~아닌"이라는 표지판을 붙이는 것이 역·이·대우입니다.

    원래 명제: p → q ("p이면 q이다")

    • 역(逆): q → p — 화살표 방향만 뒤집기
    • 이(裏): ~p → ~q — 양쪽 모두 부정하기
    • 대우(對偶): ~q → ~p — 방향도 뒤집고, 양쪽 모두 부정하기
    graph LR A["원래 명제<br/>p → q"] -- "방향 뒤집기" --> B["역<br/>q → p"] A -- "양쪽 부정" --> C["이<br/>~p → ~q"] A -- "방향 뒤집기 + 양쪽 부정" --> D["대우<br/>~q → ~p"] B -- "양쪽 부정" --> D C -- "방향 뒤집기" --> D

    알아보기: 역과 이는 서로 대우 관계입니다! 위 다이어그램에서 역(q→p)에 양쪽 부정을 하면 대우(~q→~p)가 되고, 이(~p→~q)에 방향을 뒤집어도 대우(~q→~p)가 됩니다.

    개념 2: 대우의 마법 — 진리값이 같다!¶

    가장 중요한 성질이 있습니다.

    ⭐ 원래 명제가 참이면, 대우도 반드시 참이다. ⭐ 원래 명제가 거짓이면, 대우도 반드시 거짓이다.

    하지만 역과 이는 원래 명제와 참·거짓이 다를 수 있습니다!

    구체적 예시로 확인해 볼까요?

    원래 명제: "비가 오면 땅이 젖는다" ✅ 참

    • 역: "땅이 젖으면 비가 온다" → ❌ 거짓! (스프링클러 때문에 젖을 수도 있으니까요)
    • 이: "비가 오지 않으면 땅이 젖지 않는다" → ❌ 거짓! (마찬가지 이유)
    • 대우: "땅이 젖지 않았으면 비가 오지 않았다" → ✅ 참!

    정리하기: 같은 진리값을 갖는 쌍 - 원래 명제 ↔ 대우 — 항상 진리값이 같음 - 역 ↔ 이 — 서로 진리값이 같음 (하지만 원래 명제와는 다를 수 있음)

    graph LR A["원래 명제<br/>p → q"] <-- "진리값 같음 ✅" --> D["대우<br/>~q → ~p"] B["역<br/>q → p"] <-- "진리값 같음 ✅" --> C["이<br/>~p → ~q"] A -. "진리값 다를 수 있음 ⚠️" .-> B A -. "진리값 다를 수 있음 ⚠️" .-> C

    ⚠️ 주의할 점¶

    1. 역과 대우를 헷갈리지 마세요!

    "비가 오면 땅이 젖는다"의 역은 "땅이 젖으면 비가 온다"이고, 대우는 "땅이 안 젖었으면 비가 안 왔다"입니다. 역은 참일 수도, 거짓일 수도 있지만, 대우는 원래 명제와 항상 진리값이 같습니다.

    2. "이"와 "대우"도 구분하세요!

    "이"는 양쪽만 부정(~p → ~q), "대우"는 양쪽 부정 + 방향 뒤집기(~q → ~p)입니다. 방향이 바뀌는지가 핵심!

    ✅ 점검하기¶

    1. (기본) "x가 짝수이면 x²은 짝수이다"의 역, 이, 대우를 각각 쓰세요.

    정답 확인 - **역**: "x²이 짝수이면 x는 짝수이다" (참) - **이**: "x가 짝수가 아니면 x²은 짝수가 아니다" (참) - **대우**: "x²이 짝수가 아니면 x는 짝수가 아니다" (참) 이 예시에서는 역, 이도 모두 참이지만, **항상 그런 것은 아닙니다!**

    2. (응용) "a > 3이면 a > 1이다"(참)의 역은 참인가요, 거짓인가요? 이유와 함께 답하세요.

    정답 확인 **역**: "a > 1이면 a > 3이다" → **거짓!** 반례: a = 2이면 a > 1은 참이지만 a > 3은 거짓입니다. 이처럼 원래 명제가 참이어도 역은 거짓일 수 있습니다.

    3. (심화) 탐정이 다음 단서를 얻었습니다. 대우를 활용해 결론을 내리세요. - 단서: "범인이 왼손잡이라면 글씨가 왼쪽으로 기울어진다" (참) - 현장의 메모지: 글씨가 오른쪽으로 기울어져
