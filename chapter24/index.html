    Chapter 24. AI 추천의 비밀 — 데이터 분류와 나만의 추천 알고리즘¶

    Part 8. 공통수학2 — 통계, AI의 눈으로 세상을 읽다 ⏱️ 예상 학습 시간: 50분 | 전체 과정 24차시 중 마지막 24차시

    🎯 이 장에서 배우는 것¶

    • AI 추천 시스템이 통계적 데이터 분석(유사도 계산)에 기반함을 설명할 수 있다.
    • 점수 차이 합산으로 '취향이 비슷한 사람'을 찾는 유사도 개념을 이해할 수 있다.
    • 취향 데이터를 활용해 '비슷한 친구'를 매칭하는 미니 추천 프로그램을 만들 수 있다.

    📚 핵심 개념¶

    개념 1: 협업 필터링 — "취향이 비슷한 친구가 좋아한 것, 나도 좋아할 걸?"¶

    1. 비유로 시작 🎬

    "협업 필터링은 마치 맛집을 잘 아는 단짝 친구와 같아요. 그 친구가 '여기 떡볶이 맛있어!'라고 하면, 평소 입맛이 비슷하니까 나도 맛있을 확률이 높죠. AI도 똑같은 논리로 추천합니다."

    1. 정확한 정의

    협업 필터링(Collaborative Filtering) 이란, 나와 취향이 비슷한 다른 사용자를 찾고, 그 사용자가 높이 평가했지만 내가 아직 보지 않은 콘텐츠를 추천하는 방법입니다. 넷플릭스·유튜브·멜론 등 거의 모든 추천 서비스의 핵심 원리입니다.

    1. 예시로 확인

    민수와 지은이의 장르 선호도(5점 만점)를 봅시다.

    • 민수 → 액션 5, 로맨스 2, 공포 4, 다큐 1
    • 지은 → 액션 4, 로맨스 3, 공포 5, 다큐 1

    둘 다 액션·공포를 좋아하고 다큐를 별로 안 좋아하니, 취향이 비슷합니다. 지은이가 좋아하는 새 공포 영화를 민수에게 추천하면 적중할 가능성이 높겠죠!

    개념 2: 유사도 — "얼마나 비슷한지 숫자로 재기"¶

    1. 비유로 시작 📏

    "유사도는 마치 두 사람 사이의 거리와 같아요. 거리가 가까울수록(= 차이가 작을수록) 더 비슷한 사람입니다."

    1. 정확한 정의

    여기서는 가장 직관적인 점수 차이 합산(맨해튼 거리) 방식을 사용합니다.

    유사도 점수 = 각 장르별 |내 점수 − 상대 점수|를 모두 더한 값

    이 값이 작을수록 취향이 비슷합니다. (차이가 적으니까!)

    1. 예시로 확인 — 손 계산

    나(민수)와 지은이의 유사도를 구해봅시다.

    • 액션: |5 − 4| = 1
    • 로맨스: |2 − 3| = 1
    • 공포: |4 − 5| = 1
    • 다큐: |1 − 1| = 0
    • 유사도 점수 = 1 + 1 + 1 + 0 = 3 ✅ (낮을수록 비슷!)

    💡 알아보기: 유사도 측정법은 맨해튼 거리 외에도 유클리드 거리, 코사인 유사도 등 다양합니다. 여기서 쓰는 방식은 가장 계산이 쉬운 맨해튼 거리입니다.

    flowchart LR A["🧑 나의 취향 점수"] --> C["📐 점수 차이 계산"] B["👥 다른 친구들 점수"] --> C C --> D["🏆 가장 차이가 작은 친구 = 취향 쌍둥이!"] D --> E["🎬 그 친구가 높이 평가한 콘텐츠 추천"]

    🔨 따라하기 — 나만의 추천 프로그램 만들기¶

    엔트리(Entry) 또는 파이썬으로 실습할 수 있습니다. 여기서는 파이썬 코드로 핵심 원리를 구현합니다.

    Step 1: 친구들의 취향 데이터 준비하기¶

    5명의 친구가 4개 장르(액션, 로맨스, 공포, 다큐)에 1~5점을 매겼다고 가정합니다.

    # 친구들의 장르별 선호도 (액션, 로맨스, 공포, 다큐)
friends = {
    "지은": [4, 3, 5, 1],
    "하준": [2, 5, 1, 3],
    "서연": [5, 1, 4, 2],
    "도윤": [3, 4, 2, 5],
    "유나": [4, 2, 5, 2],
}

    Step 2: 내 취향 점수 입력받기¶

    print("=== 🎬 AI 추천 시스템 ===")
print("각 장르에 1~5점을 매겨주세요!\n")

my_scores = []
genres = ["액션", "로맨스", "공포", "다큐"]

for g in genres:
    score = int(input(f"{g} 선호도 (1~5): "))
    my_scores.append(score)

print(f"\n내 취향: {my_scores}")

    실행 결과 (예시): 

    === 🎬 AI 추천 시스템 ===
각 장르에 1~5점을 매겨주세요!

액션 선호도 (1~5): 5
로맨스 선호도 (1~5): 2
공포 선호도 (1~5): 4
다큐 선호도 (1~5): 1

내 취향: [5, 2, 4, 1]

    Step 3: 유사도 계산 함수 만들기¶

    def calc_similarity(my, other):
    """점수 차이 합산 (맨해튼 거리) — 값이 작을수록 비슷!"""
    total = 0
    for i in range(len(my)):
        total += abs(my[i] - other[i])
    return total

    Step 4: 가장 비슷한 친구 찾기¶

    best_friend = ""
best_score = 9999  # 아주 큰 수로 시작

for name, scores in friends.items():
    sim = calc_similarity(my_scores, scores)
    print(f"  {name}: 유사도 점수 = {sim}")
    if sim < best_score:
        best_score = sim
        best_friend = name

print(f"\n🏆 취향 쌍둥이: {best_friend} (유사도 점수: {best_score})")

    실행 결과 (예시): 

      지은: 유사도 점수 = 3
  하준: 유사도 점수 = 10
  서연: 유사도 점수 = 1
  도윤: 유사도 점수 = 8
  유나: 유사도 점수 = 2

🏆 취향 쌍둥이: 서연 (유사도 점수: 1)

    Step 5: 추천 콘텐츠 출력하기¶

    취향 쌍둥이가 가장 높은 점수를 준 장르를 찾아 추천합니다.

    # 취향 쌍둥이의 점수 가져오기
twin_scores = friends[best_friend]

# 가장 높은 점수의 장르 찾기
max_score = max(twin_scores)
max_index = twin_scores.index(max_score)

print(f"\n🎬 추천! '{best_friend}'님이 가장 좋아하는 장르:")
print(f"   👉 {genres[max_index]} (점수: {max_score})")
print(f"\n'{genres[max_index]}' 장르의 인기 콘텐츠를 확인해보세요! 🍿")

    실행 결과: 

    🎬 추천! '서연'님이 가장 좋아하는 장르:
   👉 액션 (점수: 5)

'액션' 장르의 인기 콘텐츠를 확인해보세요! 🍿

    🤔 생각해보기: 만약 유사도 점수가 똑같은 친구가 2명이라면 어떻게 해야 할까요? 실제 AI는 이런 동점 상황을 다양한 방식으로 처리합니다.

    📝 전체 코드¶

    # === 🎬 나만의 AI 추천 시스템 ===

# 1. 친구들의 장르별 선호도 (액션, 로맨스, 공포, 다큐)
friends = {
    "지은": [4, 3, 5, 1],
    "하준": [2, 5, 1, 3],
    "서연": [5, 1, 4, 2],
    "도윤": [3, 4, 2, 5],
    "유나": [4, 2, 5, 2],
}
genres = ["액션", "로맨스", "공포", "다큐"]

# 2. 내 취향 입력
print("=== 🎬 AI 추천 시스템 ===")
print("각 장르에 1~5점을 매겨주세요!\n")
my_scores = []
for g in genres:
    score = int(input(f"{g} 선호도 (1~5): "))
    my_scores.append(score)

# 3. 유사도 계산 함수
def calc_similarity(my, other):
    total = 0
    for i in range(len(my)):
        total += abs(my[i] - other[i])
    return total

# 4. 가장 비슷한 친구 찾기
print("\n--- 유사도 계산 결과 ---")
best_friend = ""
best_score = 9999

for name, scores in friends.items():
    sim = calc_similarity(my_scores, scores)
    print(f"  {name}: 유사도 점수 = {sim}")
    if sim < best_score:
        best_score = sim
        best_friend = name

print(f"\n🏆 취향 쌍둥이: {best_friend} (유사도 점수: {best_score})")

# 5. 추천
twin_scores = friends[best_friend]
max_score = max(twin_scores)
max_index = twin_scores.index(max_score)

print(f"\n🎬 추천! '{best_friend}'님이 가장 좋아하는 장르:")
print(f"   👉 {genres[max_index]} (점수: {max_score})")
print(f"\n'{genres[max_index]}' 장르의 인기 콘텐츠를 확인해보세요! 🍿")

    ⚠️ 주의할 점¶

    1. 유사도 점수는 '작을수록' 비슷합니다! 점수가 크다는 것은 차이가 크다는 뜻이니 헷갈리지 마세요. "거리가 가까울수록 친하다"고 기억하세요.

    2. 데이터가 많을수록 추천이 정확해집니다. 친구 5명보다 50명, 500명의 데이터가 있을 때 진짜 취향 쌍둥이를 찾을 확률이 높아집니다. 실제 넷플릭스는 수억 명의 데이터를 활용합니다.

    ✅ 점검하기¶

    1. (기본) 손 계산 문제

    나의 점수가 [3, 4, 2, 5]이고, 친구 A의 점수가 [5, 4, 1, 3]일 때, 유사도 점수는?

    정답 확인 |3−5| + |4−4| + |2−1| + |5−3| = **2 + 0 + 1 + 2 = 5**

    2. (응용) 누가 더 비슷할까?

    나의 점수: [5, 1, 4, 2]. 친구 B: [4, 2, 3, 2], 친구 C: [1, 5, 1, 4]. 누구에게 추천을 받아야 할까?

    정답 확인 - 친구 B: |5−4| + |1−2| + |4−3| + |2−2| = 1+1+1+0 = **3** - 친구 C: |5−1| + |1−5| + |4−1| + |2−4| = 4+4+3+2 = **13** 유사도 점수가 **3으로 더 작은 친구 B**에게 추천을 받아야 합니다!

    3. (심화) 확장 도전 🚀

    학급 전체 30명의 실제 선호도 데이터를 수집하여 프로그램에 넣어 보세요. 5명일 때와 30명일 때, 추천 결과가 얼마나 달라지는지 비교해 봅시다.

    힌트 확인 `friends` 딕셔너리에 30명의 데이터를 추가하면 됩니다. 사람이 많아질수록 나와 유사도 점수 0~2인 '진짜 취향 쌍둥이'가 나타날 확률이 높아져 추천 정확도가 올라갑니다.

    📌 정리하기: AI 추천 시스템의 핵심은 ① 사용자 취향을 숫자(데이터)로 바꾸고 ② 유사도를 계산해 비슷한 사람을 찾고 ③ 그 사람이 좋아한 것을 추천하는 세 단계입니다. 통계적 데이터 분석이 AI의 '눈'이 되는 셈이죠!
