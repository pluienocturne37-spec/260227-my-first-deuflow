    제11장. 순서가 중요해! — 순열과 암호 만들기¶

    Part 4. 공통수학1 — 경우의 수, 확률로 게임을 설계하다

    🎯 이 장에서 배우는 것¶

    • 순열의 개념을 '순서가 있는 선택'으로 설명할 수 있다
    • nPr 공식의 의미를 실생활 예시로 이해할 수 있다
    • 엔트리에서 간단한 시저 암호 인코더/디코더를 만들 수 있다

    📚 핵심 개념¶

    🔑 개념 1: 순열 — 순서가 있는 선택¶

    비유로 시작 🎒

    순열은 마치 줄 세우기와 같아요. 친구 A, B, C 세 명이 있을 때, "A → B → C" 순서와 "C → B → A" 순서는 다른 경우로 칩니다. 단순히 '누구를 뽑느냐'가 아니라 '어떤 순서로 뽑느냐'까지 따지는 것이 순열입니다.

    정확한 정의 📐

    순열(Permutation): 서로 다른 n개에서 r개를 골라 순서대로 나열하는 경우의 수

    $$_nP_r = n \times (n-1) \times (n-2) \times \cdots \times (n-r+1)$$

    이를 팩토리얼(계승)로 쓰면:

    $$_nP_r = \frac{n!}{(n-r)!}$$

    예시로 확인 ✏️

    문제: 5명 중 3명을 뽑아 회장, 부회장, 총무를 정하는 경우의 수는?

    • 첫 번째 자리(회장): 5명 중 택 1
    • 두 번째 자리(부회장): 남은 4명 중 택 1
    • 세 번째 자리(총무): 남은 3명 중 택 1
    • → ₅P₃ = 5 × 4 × 3 = 60가지
    flowchart LR A["5명 중 1명 선택<br/>(회장)"] -->|"남은 4명"| B["4명 중 1명 선택<br/>(부회장)"] B -->|"남은 3명"| C["3명 중 1명 선택<br/>(총무)"] C --> D["5 × 4 × 3 = 60가지"]

    💡 생각해보기: 만약 순서를 따지지 않고 3명을 그냥 뽑기만 한다면? 그건 다음 장에서 배울 '조합'입니다!

    🔑 개념 2: 시저 암호 — 순열의 활용¶

    비유로 시작 🏛️

    약 2000년 전, 로마의 장군 율리우스 카이사르(시저)는 전쟁터에서 비밀 편지를 보낼 때 알파벳을 일정 칸수만큼 밀어서 암호를 만들었어요. 예를 들어 3칸 밀면 A → D, B → E, C → F가 됩니다.

    정확한 정의 📐

    시저 암호: 알파벳 각 글자를 고정된 칸수(키, key)만큼 이동시켜 다른 글자로 바꾸는 치환 암호

    • 암호화(인코딩): 글자 위치에 키를 더한다
    • 복호화(디코딩): 암호 글자 위치에서 키를 뺀다
    • 26자를 넘어가면? → 나머지 연산(mod 26)으로 순환!

    예시로 확인 ✏️

    키 = 3일 때 "HELLO"를 암호화하면:

    • H(7번째) → K(10번째)
    • E(4번째) → H(7번째)
    • L(11번째) → O(14번째)
    • L(11번째) → O(14번째)
    • O(14번째) → R(17번째)
    • → 암호문: "KHOOR"

    💡 알아보기: 알파벳 26자를 재배열하는 모든 경우의 수는 ₂₆P₂₆ = 26! ≈ 4 × 10²⁶가지입니다. 시저 암호는 이 중 밀기만 사용하는 26가지에 해당해요. 경우의 수가 적어서 현대에는 쉽게 뚫리지만, 순열의 원리를 이해하기에 아주 좋은 예시입니다!

    🔨 따라하기: 시저 암호 프로그램 만들기¶

    엔트리(또는 Python)로 글자를 입력하면 암호화/복호화해주는 프로그램을 만들어 봅시다.

    Step 1: 알파벳과 번호 매핑 이해하기¶

    알파벳 A~Z를 0~25 번호로 대응시킵니다.

    # 알파벳 목록 만들기
alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
# A=0, B=1, C=2, ... Z=25

    Step 2: 암호화 함수 만들기¶

    def encrypt(text, key):
    result = ""
    for char in text.upper():
        if char in alphabet:
            idx = alphabet.index(char)        # 글자 → 번호
            new_idx = (idx + key) % 26        # 키만큼 밀기
            result += alphabet[new_idx]       # 번호 → 새 글자
        else:
            result += char                    # 알파벳 아니면 그대로
    return result

    실행 결과: 

    encrypt("HELLO", 3)  →  "KHOOR"

    Step 3: 복호화 함수 만들기¶

    def decrypt(text, key):
    result = ""
    for char in text.upper():
        if char in alphabet:
            idx = alphabet.index(char)
            new_idx = (idx - key) % 26        # 키만큼 되돌리기
            result += alphabet[new_idx]
        else:
            result += char
    return result

    실행 결과: 

    decrypt("KHOOR", 3)  →  "HELLO"

    Step 4: 사용자 입력 받기¶

    message = input("메시지를 입력하세요: ")
key = int(input("밀기 칸수(키)를 입력하세요: "))
mode = input("암호화(E) / 복호화(D): ")

if mode.upper() == "E":
    print("암호문:", encrypt(message, key))
else:
    print("원문:", decrypt(message, key))

    Step 5: 실행해보기¶

    메시지를 입력하세요: MATH IS FUN
밀기 칸수(키)를 입력하세요: 5
암호화(E) / 복호화(D): E
암호문: RFYM NX KZS
    flowchart TD A["사용자 입력<br/>메시지 + 키 + 모드"] --> B{"암호화? 복호화?"} B -->|"암호화 E"| C["각 글자 번호 + 키<br/>(mod 26)"] B -->|"복호화 D"| D["각 글자 번호 - 키<br/>(mod 26)"] C --> E["암호문 출력"] D --> F["원문 출력"]

    📝 전체 코드¶

    # 시저 암호 인코더/디코더
alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

def encrypt(text, key):
    result = ""
    for char in text.upper():
        if char in alphabet:
            idx = alphabet.index(char)
            new_idx = (idx + key) % 26
            result += alphabet[new_idx]
        else:
            result += char
    return result

def decrypt(text, key):
    result = ""
    for char in text.upper():
        if char in alphabet:
            idx = alphabet.index(char)
            new_idx = (idx - key) % 26
            result += alphabet[new_idx]
        else:
            result += char
    return result

# 메인 프로그램
message = input("메시지를 입력하세요: ")
key = int(input("밀기 칸수(키)를 입력하세요: "))
mode = input("암호화(E) / 복호화(D): ")

if mode.upper() == "E":
    print("암호문:", encrypt(message, key))
else:
    print("원문:", decrypt(message, key))

    ⚠️ 주의할 점¶

    1. 순열 ≠ 조합! 순서가 핵심입니다 🚨

    "A, B, C를 뽑았다"와 "C, A, B를 뽑았다"가 같으면 조합, 다르면 순열입니다. 암호에서 글자 배치 순서가 바뀌면 완전히 다른 암호문이 되므로, 이것은 순열의 영역입니다.

    2. mod 26 연산을 빼먹지 마세요 🔄

    Z(25번) + 3 = 28인데, 알파벳은 26개뿐입니다. 28 % 26 = 2 → C가 됩니다. 이 순환 처리를 빼먹으면 프로그램이 오류를 냅니다.

    ✅ 점검하기¶

    기본 문제

    1. 5명의 학생 중 3명을 뽑아 일렬로 세우는 경우의 수(₅P₃)를 구하세요.

    정답 확인 ₅P₃ = 5 × 4 × 3 = **60가지**

    2. 시저 암호에서 키가 7일 때, "CAT"을 암호화하면?

    정답 확인 - C(2) + 7 = 9 → **J** - A(0) + 7 = 7 → **H** - T(19) + 7 = 26 → 26 % 26 = 0 → **A** - 답: **"JHA"**

    응용 문제

    3. 0~9까지 숫자 10개로 4자리 비밀번호를 만들 때(같은 숫자 반복 불가), 가능한 비밀번호 수는?

    정답 확인 ₁₀P₄ = 10 × 9 × 8 × 7 = **5,040가지** 순서가 중요합니다! 1234와 4321은 다른 비밀번호이니까요.

    🏆 도전 과제

    위 프로그램에서 키를 고정값이 아니라 1부터 25까지 모두 시도해서, 암호문을 전부 해독하는 "브루트포스 해독기"를 만들어 보세요. 어떤 키일 때 의미 있는 문장이 나오는지 찾아보는 것이 핵심입니다!

    📌 정리하기

    • 순열(ₙPᵣ): 서로 다른 n개에서 r개를 뽑아 순서대로 나열하는 경우의 수
    • 공식: ₙPᵣ = n × (n-1) × … × (n-r+1)
    • 시저 암호: 알파벳을 일정 칸수만큼 밀어 치환하는 것 → 순열의 실생활 활용
    • mod 연산: 순환 구조를 다룰 때 필수!
