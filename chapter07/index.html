    Chapter 7. 정답을 찾아라 — 일차·이차방정식과 자동 풀이기¶

    Part 3. 공통수학1 — 방정식과 부등식, 조건을 코딩하다

    🎯 이 장에서 배우는 것¶

    • 방정식이 '미지수를 찾는 문제'임을 이해하고, 컴퓨터가 반복 탐색으로 해를 찾는 원리를 설명할 수 있다
    • 파이썬 반복문과 조건문을 활용해 일차·이차방정식의 해를 자동으로 찾는 프로그램을 만들 수 있다
    • 컴퓨터의 '전수 탐색' 방법과 수학적 풀이의 차이를 비교할 수 있다

    📚 핵심 개념¶

    개념 1: 방정식 — 범인을 찾아라! 🔍¶

    비유로 시작

    방정식은 마치 범인 찾기 게임과 같아요. "키가 175cm이고, 안경을 쓴 사람을 찾아라!" — 이런 조건이 주어지면 용의자 한 명씩 확인하잖아요? 방정식도 똑같습니다. "어떤 조건을 만족하는 숫자 x를 찾아라!" 가 바로 방정식이에요.

    정확한 정의

    방정식(equation) 이란 미지수(아직 모르는 값)를 포함하는 등식에서, 그 등식을 참으로 만드는 미지수의 값(해) 을 찾는 문제입니다.

    예시로 확인

    2x + 3 = 11 이라는 방정식이 있다면?

    • x = 0 → 2×0 + 3 = 3 → ❌ 11이 아님
    • x = 1 → 2×1 + 3 = 5 → ❌
    • x = 2 → 2×2 + 3 = 7 → ❌
    • x = 3 → 2×3 + 3 = 9 → ❌
    • x = 4 → 2×4 + 3 = 11 → ✅ 정답!

    이렇게 하나씩 넣어보며 찾는 방법, 사람은 귀찮지만 컴퓨터는 아주 잘합니다!

    개념 2: 전수 탐색 — 컴퓨터의 무식한(?) 힘 💪¶

    비유로 시작

    자물쇠 비밀번호 4자리를 잊어버렸다고 해볼까요? 사람이라면 포기할 수도 있지만, 컴퓨터는 0000부터 9999까지 1만 개를 1초도 안 되어 다 시도할 수 있어요. 이것이 바로 전수 탐색(Brute Force) 입니다.

    정확한 정의

    전수 탐색이란 가능한 모든 값을 하나씩 대입해보면서 조건을 만족하는 답을 찾는 방법입니다. 영어로 Brute Force(브루트 포스, "무차별 대입")라고 부릅니다.

    수학적 풀이 vs 전수 탐색 비교

    flowchart LR A["2x + 3 = 11"] --> B["수학적 풀이"] A --> C["전수 탐색"] B --> D["2x = 8\nx = 4\n🎯 바로 정답"] C --> E["x=0? ❌\nx=1? ❌\nx=2? ❌\nx=3? ❌\nx=4? ✅"]
    • 수학적 풀이: 공식을 이용해 단번에 답을 구함 → 빠르고 우아함 ✨
    • 전수 탐색: 모든 경우를 대입해봄 → 느리지만 확실함, 공식을 몰라도 OK 🔨

    💡 생각해보기: 수학 공식이 없는 복잡한 문제라면? 그때 컴퓨터의 전수 탐색이 빛을 발합니다!

    🔨 따라하기: 방정식 자동 풀이기 만들기¶

    Step 1: 문제 설정하기¶

    먼저 풀고 싶은 방정식을 정합시다.

    미션: 2x + 3 = 11 에서 x를 찾아라!

    프로그램의 전체 흐름은 이렇습니다:

    flowchart TD A["x를 0으로 설정"] --> B["2x + 3 을 계산"] B --> C{"결과가 11인가?"} C -- "Yes ✅" --> D["정답 출력하고 끝!"] C -- "No ❌" --> E["x를 1 증가"] E --> B

    Step 2: 기본 반복 탐색 코드 작성¶

    # 방정식: 2x + 3 = 11 의 해를 찾자!
for x in range(0, 100):      # x에 0부터 99까지 하나씩 넣어본다
    if 2 * x + 3 == 11:      # 등식이 성립하면?
        print(f"정답! x = {x}")
        break                 # 찾았으니 반복 중단!

    실행 결과: 

    정답! x = 4

    💡 break는 "그만!"이라는 뜻이에요. 정답을 찾았으면 더 탐색할 필요가 없으니까요.

    Step 3: 탐색 과정을 눈으로 보기¶

    컴퓨터가 어떻게 찾아가는지 과정을 출력해볼까요?

    # 탐색 과정을 보여주는 버전
for x in range(0, 100):
    result = 2 * x + 3
    print(f"x = {x} → 2×{x}+3 = {result}", end="")

    if result == 11:
        print(" ✅ 정답!")
        break
    else:
        print(" ❌")

    실행 결과: 

    x = 0 → 2×0+3 = 3 ❌
x = 1 → 2×1+3 = 5 ❌
x = 2 → 2×2+3 = 7 ❌
x = 3 → 2×3+3 = 9 ❌
x = 4 → 2×4+3 = 11 ✅ 정답!

    범인을 한 명씩 조사하다가 딱 찾아낸 느낌이죠? 🕵️

    Step 4: 어떤 방정식이든 풀 수 있게 업그레이드¶

    매번 코드를 고치기 귀찮으니, 사용자가 직접 입력하는 풀이기로 만들어봅시다.

    # 일차방정식 ax + b = c 자동 풀이기
print("=== 일차방정식 풀이기 ===")
print("ax + b = c 형태를 풀어줍니다!\n")

a = int(input("a 값을 입력하세요: "))
b = int(input("b 값을 입력하세요: "))
c = int(input("c 값을 입력하세요: "))

found = False  # 정답을 찾았는지 기록

for x in range(-1000, 1001):  # 음수도 탐색!
    if a * x + b == c:
        print(f"\n🎉 정답! x = {x}")
        found = True
        break

if not found:
    print("\n😢 -1000~1000 범위에서 정수 해를 못 찾았습니다.")

    실행 결과 (a=3, b=-5, c=7 입력 시): 

    === 일차방정식 풀이기 ===
ax + b = c 형태를 풀어줍니다!

a 값을 입력하세요: 3
b 값을 입력하세요: -5
c 값을 입력하세요: 7

🎉 정답! x = 4

    📌 알아보기: range(-1000, 1001)로 범위를 넓힌 이유는 해가 음수일 수도 있기 때문입니다. 예를 들어 2x + 10 = 4의 해는 x = -3이에요!

    Step 5: 🚀 도전 — 이차방정식도 풀어보자!¶

    이차방정식 x² - 5x + 6 = 0은 해가 2개일 수 있습니다. 코드를 조금 바꿔볼까요?

    # 이차방정식 x² - 5x + 6 = 0 풀이기
print("=== 이차방정식 x²- 5x + 6 = 0 풀이기 ===\n")

solutions = []  # 정답을 모아두는 리스트

for x in range(-100, 101):
    if x**2 - 5*x + 6 == 0:       # x² - 5x + 6 의 값이 0이면
        solutions.append(x)         # 정답 목록에 추가

if solutions:
    print(f"🎉 정답: x = {solutions}")
else:
    print("😢 정수 해를 찾지 못했습니다.")

    실행 결과: 

    === 이차방정식 x²- 5x + 6 = 0 풀이기 ===

🎉 정답: x = [2, 3]

    핵심 차이: 일차방정식과 달리 break를 쓰지 않았어요! 이차방정식은 해가 2개일 수 있으니 끝까지 탐색해야 합니다.

    📝 전체 코드¶

    # ============================================
# 🔍 만능 방정식 풀이기 (일차 + 이차)
# ============================================

print("🔍 방정식 자동 풀이기")
print("1: 일차방정식 (ax + b = c)")
print("2: 이차방정식 (ax² + bx + c = 0)\n")

choice = int(input("유형을 선택하세요 (1 또는 2): "))

a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))

solutions = []

for x in range(-1000, 1001):
    if choice == 1:
        # 일차방정식: ax + b = c  →  ax + b - c = 0
        if a * x + b == c:
            solutions.append(x)
    elif choice == 2:
        # 이차방정식: ax² + bx + c = 0
        if a * x**2 + b * x + c == 0:
            solutions.append(x)

if solutions:
    print(f"\n🎉 정답: x = {solutions}")
else:
    print("\n😢 -1000~1000 범위에서 정수 해를 찾지 못했습니다.")

    ⚠️ 주의할 점¶

    1. 전수 탐색은 정수 해만 찾을 수 있어요!

    2x + 3 = 8의 해는 x = 2.5인데, range()는 정수만 만들어주기 때문에 이 해를 놓칩니다. 소수 해까지 찾으려면 더 정교한 방법이 필요해요. (이것은 나중에 배웁니다!)

    2. 탐색 범위를 잘 설정하세요!

    range(0, 10)처럼 범위가 너무 좁으면 정답이 범위 밖에 있을 수 있고, range(-1000000, 1000001)처럼 너무 넓으면 시간이 오래 걸립니다. 적절한 범위 설정이 중요합니다.

    📌 정리하기: 이 장에서 배운 핵심 - 방정식 = 조건을 만족하는 미지수를 찾는 문제 - 전수 탐색 = 가능한 값을 모두 대입해보는 방법 (Brute Force) - for + if만으로 방정식 풀이기를 만들 수 있다! - 수학 공식은 우아하고, 컴퓨터 탐색은 확실하다 — 둘 다 중요!

    ✅ 점검하기¶

    1. 기본 — 5x - 10 = 0의 해를 전수 탐색으로 찾으려면, 조건문을 어떻게 작성해야 할까요?

    정답 확인 
    if 5 * x - 10 == 0:
    이렇게 작성하면 x = 2일 때 조건이 참이 됩니다. (5×2 - 10 = 0 ✅)

    2. 응용 — 이차방정식 x² - 4 = 0을 전수 탐색 코드로 풀면 정답이 몇 개 나올까요? 해를 모두 쓰세요.

    정답 확인 정답은 **2개**: x = -2, x = 2 - (-2)² - 4 = 4 - 4 = 0 ✅ - 2² - 4 = 4 - 4 = 0 ✅ 이차방정식은 해가 최대 2개이므로 `break` 없이 끝까지 탐색해야 합니다.

    3. 심화 — 전수 탐색 방식이 수학 공식보다 유리한 상황은 어떤 경우일까요?

    정답 확인 풀이 공식이 복잡하거나 존재하지 않는 고차방정식, 또는 여러 조건이 동시에 걸린 복잡한 문제에서 전수 탐색이 유리합니다. 예를 들어 "x² + y² = 25를 만족하는 정수 쌍 (x, y)를 모두 찾아라" 같은 문제는 컴퓨터의 반복 탐색이 훨씬 편리합니다.

    🔗 다음 장 미리보기¶

    Chapter 8에서는 방정식의 쌍둥이, 부등식을 다룹니다! "x가 얼마 이상이면 조건을 만족할까?"처럼, 정답이 하나가 아니라 범위로 나오는 문제를 코딩으로 풀어봅니다. if문의 비교 연산자(<, >, <=, >=)가 본격적으로 활약할 거예요! 🎯
