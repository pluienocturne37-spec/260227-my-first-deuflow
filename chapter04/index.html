    컴퓨터는 덧셈밖에 모른다 — 이진수와 다항식의 만남¶

    Part 2 | 공통수학1 — 다항식, 코드로 계산하다 | 4차시 (50분)

    🎯 이 장에서 배우는 것¶

    • 이진수가 무엇인지 설명하고, 십진수를 이진수로 변환할 수 있다
    • 이진수의 자릿값 구조가 다항식의 전개와 같음을 설명할 수 있다
    • 파이썬으로 십진수→이진수 변환기를 만들어 결과를 확인할 수 있다

    🤔 생각 열기¶

    여러분의 스마트폰은 약 1,677만 가지 색을 표현합니다. 그런데 컴퓨터 내부에는 오직 0과 1, 딱 두 가지 신호만 흐르고 있어요. 어떻게 두 숫자만으로 이 모든 것이 가능할까요?

    비밀은 이진수(binary)에 있습니다. 그리고 놀랍게도, 이진수를 이해하는 열쇠는 우리가 이미 배운 다항식에 숨어 있습니다.

    📚 핵심 개념¶

    개념 1: 이진수 — 0과 1로 세상을 세다¶

    1) 비유로 시작

    이진수는 마치 스위치 여러 개를 나란히 놓은 것과 같아요. 각 스위치는 켜짐(1) 또는 꺼짐(0), 두 상태뿐입니다. 스위치가 많아질수록 표현할 수 있는 수가 늘어납니다.

    2) 정확한 정의

    • 십진수: 0~9까지 10개 숫자를 사용하며, 자릿값이 10의 거듭제곱으로 커지는 수 체계
    • 이진수: 0과 1 두 개 숫자만 사용하며, 자릿값이 2의 거듭제곱으로 커지는 수 체계

    3) 예시로 확인

    십진수 13을 이진수로 바꿔 봅시다.

    13 ÷ 2 = 6 ... 나머지 1
 6 ÷ 2 = 3 ... 나머지 0
 3 ÷ 2 = 1 ... 나머지 1
 1 ÷ 2 = 0 ... 나머지 1

    나머지를 아래에서 위로 읽으면 → 1101₂

    💡 알아보기: 아래첨자 ₂는 "이것은 이진수입니다"라는 표시예요. 마찬가지로 십진수는 ₁₀을 붙이기도 합니다.

    개념 2: 이진수 = 다항식의 전개!¶

    여기가 이번 수업의 핵심 발견입니다.

    십진수 13은 이진수로 1101₂라고 했죠. 이것을 자릿값으로 풀어 써 봅시다.

    1×2³ + 1×2² + 0×2¹ + 1×2⁰

    계산하면:

    8 + 4 + 0 + 1 = 13 ✅

    이 구조, 어디서 본 적 없나요? 바로 다항식입니다!

    graph LR A["다항식 f(x) = aₙxⁿ + ... + a₁x + a₀"] --> B["x = 10 → 십진수"] A --> C["x = 2 → 이진수"] A --> D["x = 8 → 8진수"]

    🧠 생각해보기: 십진수 247을 다항식으로 쓰면 2×10² + 4×10¹ + 7×10⁰ 입니다. 이진수 1101₂도 1×2³ + 1×2² + 0×2¹ + 1×2⁰ 입니다. 자릿값 × 밑(base)의 거듭제곱이라는 구조가 완전히 똑같죠!

    정리하면:

    • 다항식: 계수 × 변수의 거듭제곱의 합
    • 진법 표현: 각 자릿수 × 밑의 거듭제곱의 합
    • 수 체계는 곧 "밑(base)에 구체적 값을 대입한 다항식" 입니다

    🔨 따라하기: 이진수 변환기 만들기¶

    파이썬의 나눗셈(//) 과 나머지(%) 연산을 사용해서, 십진수를 입력하면 이진수로 바꿔주는 프로그램을 만들어 봅시다.

    Step 1: 핵심 원리 — 나누고 나머지를 모으기¶

    2로 나눈 나머지를 계속 모으면 이진수 각 자릿수가 됩니다.

    # 13을 한 번 나눠보기
number = 13
remainder = number % 2   # 나머지 → 이진수의 맨 끝자리
quotient = number // 2   # 몫 → 다음에 다시 나눌 수
print(f"{number} ÷ 2 = {quotient} ... 나머지 {remainder}")

    실행 결과: 

    13 ÷ 2 = 6 ... 나머지 1

    Step 2: 반복문으로 끝까지 나누기¶

    몫이 0이 될 때까지 반복합니다.

    number = 13
binary_digits = ""  # 이진수 자릿수를 모을 문자열

while number > 0:
    remainder = number % 2
    binary_digits = str(remainder) + binary_digits  # 앞쪽에 붙이기!
    number = number // 2

print(f"이진수: {binary_digits}")

    실행 결과: 

    이진수: 1101

    💡 나머지를 앞쪽에 붙이는 이유: 가장 먼저 나온 나머지가 가장 작은 자릿수(맨 오른쪽)이기 때문이에요. str(remainder) + binary_digits 순서에 주의하세요!

    Step 3: 다항식으로 검증하기¶

    변환 결과가 맞는지, 다항식 계산으로 되돌려 확인합니다.

    binary_str = "1101"
result = 0

for i, digit in enumerate(binary_str):
    power = len(binary_str) - 1 - i        # 거듭제곱 차수
    value = int(digit) * (2 ** power)       # 계수 × 2의 거듭제곱
    print(f"  {digit} × 2^{power} = {value}")
    result += value

print(f"다항식 합산 결과: {result}")

    실행 결과: 

      1 × 2^3 = 8
  1 × 2^2 = 4
  0 × 2^1 = 0
  1 × 2^0 = 1
다항식 합산 결과: 13

    Step 4: 사용자 입력 받는 완성형¶

    number = int(input("십진수를 입력하세요: "))
original = number  # 원래 값 보관
binary_digits = ""

if number == 0:
    binary_digits = "0"

while number > 0:
    remainder = number % 2
    binary_digits = str(remainder) + binary_digits
    number = number // 2

print(f"{original}(10진수) → {binary_digits}(2진수)")

    실행 결과 (42를 입력한 경우): 

    42(10진수) → 101010(2진수)

    📝 전체 코드¶

    # === 이진수 변환기 + 다항식 검증 ===

# [1] 십진수 → 이진수 변환
number = int(input("십진수를 입력하세요: "))
original = number
binary_digits = ""

if number == 0:
    binary_digits = "0"

while number > 0:
    remainder = number % 2
    binary_digits = str(remainder) + binary_digits
    number = number // 2

print(f"\n{original}(10진수) → {binary_digits}(2진수)")

# [2] 다항식 전개로 검증
print(f"\n[검증] 다항식 전개:")
result = 0
terms = []  # 식을 보기 좋게 모으기

for i, digit in enumerate(binary_digits):
    power = len(binary_digits) - 1 - i
    value = int(digit) * (2 ** power)
    terms.append(f"{digit}×2^{power}")
    result += value

print(" + ".join(terms))
print(f"= {result} ✅" if result == original else f"= {result} ❌")

    ⚠️ 주의할 점¶

    1. 나머지를 붙이는 순서를 헷갈리지 마세요!

    • ⭕ str(remainder) + binary_digits — 새 나머지를 앞에 붙이기
    • ❌ binary_digits + str(remainder) — 이렇게 하면 자릿수가 뒤집힙니다

    2. 입력값 0을 잊지 마세요!

    while number > 0은 number가 0이면 한 번도 실행되지 않습니다. 그래서 if number == 0: binary_digits = "0" 처리가 필요합니다.

    ✅ 점검하기¶

    기본 ① 십진수 25를 손으로 이진수로 변환하세요. (2로 나누기 반복)

    정답 확인 
    25 ÷ 2 = 12 ... 1
12 ÷ 2 = 6  ... 0
 6 ÷ 2 = 3  ... 0
 3 ÷ 2 = 1  ... 1
 1 ÷ 2 = 0  ... 1
    나머지를 아래→위로 읽으면: **11001**₂ 검증: 1×2⁴ + 1×2³ + 0×2² + 0×2¹ + 1×2⁰ = 16 + 8 + 0 + 0 + 1 = **25** ✅

    응용 ② 이진수 110010₂을 다항식으로 전개하여 십진수를 구하세요.

    정답 확인 1×2⁵ + 1×2⁴ + 0×2³ + 0×2² + 1×2¹ + 0×2⁰ = 32 + 16 + 0 + 0 + 2 + 0 = **50**

    심화 🚀 ③ 변환기를 8진수 변환기로 바꾸려면 코드에서 어디를 고쳐야 할까요? 직접 수정해서 십진수 100을 8진수로 변환해 보세요.

    정답 확인 `% 2`를 `% 8`로, `// 2`를 `// 8`로 바꾸면 됩니다! 
    number = 100
octal_digits = ""
while number > 0:
    remainder = number % 8     # 여기!
    octal_digits = str(remainder) + octal_digits
    number = number // 8       # 여기!
print(octal_digits)  # 결과: 144
    검증: 1×8² + 4×8¹ + 4×8⁰ = 64 + 32 + 4 = **100** ✅ 이것은 다항식 f(x)에서 x=2를 대입하느냐, x=8을 대입하느냐의 차이일 뿐입니다!

    📌 정리하기

    • 컴퓨터는 0과 1(이진수)만 사용하며, 모든 수를 2의 거듭제곱의 합으로 표현한다
    • 이 구조는 계수 × 밑의 거듭제곱의 합, 즉 다항식의 전개와 정확히 같다
    • 밑(base)만 바꾸면 2진수, 8진수, 10진수 모두 같은 다항식 틀로 설명된다
    • % 2(나머지)와 // 2(몫) 반복으로 진법 변환 프로그램을 만들 수 있다
