    Chapter 8. 만약 ~라면 — 부등식과 조건 분기의 세계¶

    Part 3. 공통수학1 — 방정식과 부등식, 조건을 코딩하다

    🎯 이 장에서 배우는 것¶

    • 부등식이 '범위를 정하는 조건'임을 이해하고 실생활 예시를 들 수 있다
    • 파이썬 if-else 구조를 활용해 조건에 따라 다른 결과를 출력할 수 있다
    • 놀이공원 키 제한 시뮬레이터를 만들어 부등식의 해 집합을 체험할 수 있다

    📚 핵심 개념¶

    개념 1: 부등식 — 범위를 정하는 울타리¶

    🎢 상상해보세요. 놀이공원 롤러코스터 앞에 이런 안내판이 있습니다.

    "키 140cm 이상만 탑승 가능"

    이 안내판을 수학으로 쓰면 이렇습니다.

    $$키 \geq 140$$

    이것이 바로 부등식입니다.

    1. 비유로 시작

    부등식은 마치 놀이공원 입구의 키 재는 막대와 같아요. 방정식(=)이 "딱 이 값!"이라는 정확한 점을 찍는 거라면, 부등식(≥, ≤, >, <)은 "여기서부터 저기까지 전부 OK!" 라고 범위를 긋는 겁니다.

    2. 정확한 정의

    • 부등식: 부등호(>, <, ≥, ≤)를 사용해 수의 대소 관계를 나타낸 식
    • 부등식의 해: 부등식을 참으로 만드는 모든 값의 범위

    3. 부등호 정리

    • > : 크다 (초과) → 예: x > 5는 "5보다 큰 수 전부"
    • < : 작다 (미만) → 예: x < 10은 "10보다 작은 수 전부"
    • ≥ : 크거나 같다 (이상) → 예: x ≥ 140은 "140 포함, 그 이상 전부"
    • ≤ : 작거나 같다 (이하) → 예: x ≤ 200은 "200 포함, 그 이하 전부"

    💡 알아보기: "이상/이하"는 그 값을 포함하고, "초과/미만"은 그 값을 포함하지 않습니다. 키 ≥ 140이면 정확히 140cm인 사람도 탈 수 있어요!

    개념 2: if-else — 코드로 만드는 조건 분기¶

    놀이공원 직원은 매번 키를 재고 판단합니다.

    "140 이상이면 → 탑승 가능, 아니면 → 탑승 불가"

    이 판단 과정을 코드로 옮기면 if-else가 됩니다.

    1. 비유로 시작

    if-else는 마치 갈림길 표지판과 같아요. "조건이 참이면 왼쪽 길, 거짓이면 오른쪽 길"처럼 프로그램의 흐름을 두 갈래로 나눕니다.

    2. 구조

    if 조건:
    # 조건이 참일 때 실행
else:
    # 조건이 거짓일 때 실행

    3. 부등식과 if문의 연결

    flowchart TD A["키를 입력받는다"] --> B{"키 >= 140?"} B -- "참 (True)" --> C["🎢 탑승 가능!"] B -- "거짓 (False)" --> D["🚫 탑승 불가"]

    💡 생각해보기: 수학 부등식 키 ≥ 140의 해 집합은 {140, 141, 142, ...} 처럼 조건을 만족하는 모든 값입니다. if문은 입력된 하나의 값이 이 해 집합에 속하는지 아닌지 판별하는 역할을 합니다.

    🔨 따라하기: 놀이공원 키 제한 시뮬레이터¶

    Step 1: 기본 탑승 판단기¶

    키를 입력받아 롤러코스터 탑승 가능 여부를 판단합니다.

    코드:

    # 🎢 롤러코스터 탑승 판단기
height = int(input("키를 입력하세요(cm): "))

if height >= 140:
    print("✅ 탑승 가능! 즐거운 시간 보내세요! 🎢")
else:
    print("❌ 탑승 불가. 키가 140cm 이상이어야 합니다.")

    실행 결과:

    키를 입력하세요(cm): 135
❌ 탑승 불가. 키가 140cm 이상이어야 합니다.

    키를 입력하세요(cm): 152
✅ 탑승 가능! 즐거운 시간 보내세요! 🎢

    Step 2: 여러 놀이기구 — 연립부등식의 등장¶

    놀이공원에는 놀이기구마다 조건이 다릅니다.

    • 회전목마: 제한 없음
    • 범퍼카: 키 ≥ 120
    • 롤러코스터: 키 ≥ 140
    • 자이로드롭: 140 ≤ 키 ≤ 190 (너무 커도 안 됨!)

    자이로드롭의 조건을 수학으로 쓰면 연립부등식입니다.

    $$140 \leq 키 \leq 190$$

    이것은 두 부등식이 동시에 성립해야 한다는 뜻입니다.

    $$키 \geq 140 \quad \textbf{그리고} \quad 키 \leq 190$$

    코드:

    # 🎪 놀이공원 전체 시뮬레이터
height = int(input("키를 입력하세요(cm): "))

print(f"\n📏 입력한 키: {height}cm")
print("=" * 30)

# 회전목마: 제한 없음
print("🎠 회전목마: ✅ 탑승 가능")

# 범퍼카: 키 >= 120
if height >= 120:
    print("🚗 범퍼카: ✅ 탑승 가능")
else:
    print("🚗 범퍼카: ❌ 탑승 불가 (120cm 이상)")

# 롤러코스터: 키 >= 140
if height >= 140:
    print("🎢 롤러코스터: ✅ 탑승 가능")
else:
    print("🎢 롤러코스터: ❌ 탑승 불가 (140cm 이상)")

# 자이로드롭: 140 <= 키 <= 190 (연립부등식!)
if height >= 140 and height <= 190:
    print("🗼 자이로드롭: ✅ 탑승 가능")
else:
    print("🗼 자이로드롭: ❌ 탑승 불가 (140~190cm)")

    실행 결과:

    키를 입력하세요(cm): 155

📏 입력한 키: 155cm
==============================
🎠 회전목마: ✅ 탑승 가능
🚗 범퍼카: ✅ 탑승 가능
🎢 롤러코스터: ✅ 탑승 가능
🗼 자이로드롭: ✅ 탑승 가능

    💡 알아보기: and는 "그리고"라는 뜻입니다. 수학에서 연립부등식이 "두 조건을 동시에 만족"하는 것처럼, and는 양쪽 조건이 모두 참일 때만 전체가 참이 됩니다.

    Step 3: 탑승 가능 개수 세기¶

    코드:

    # 🏆 탑승 가능 놀이기구 개수 세기
height = int(input("키를 입력하세요(cm): "))
count = 1  # 회전목마는 항상 탑승 가능

if height >= 120:
    count = count + 1  # 범퍼카

if height >= 140:
    count = count + 1  # 롤러코스터

if 140 <= height <= 190:  # 파이썬은 이렇게 간결하게 쓸 수 있어요!
    count = count + 1  # 자이로드롭

print(f"\n🎪 탑승 가능 놀이기구: {count}개 / 4개")

    실행 결과:

    키를 입력하세요(cm): 195

🎪 탑승 가능 놀이기구: 3개 / 4개

    키 195cm → 자이로드롭만 못 타요. 부등식 140 ≤ 키 ≤ 190에서 195는 해가 아니기 때문!

    📝 전체 코드¶

    # ==========================================
# 🎪 놀이공원 키 제한 시뮬레이터
# 부등식과 조건 분기(if-else)의 만남
# ==========================================

height = int(input("키를 입력하세요(cm): "))
count = 1  # 회전목마는 항상 OK

print(f"\n📏 입력한 키: {height}cm")
print("=" * 30)

# 놀이기구 1: 회전목마 (제한 없음)
print("🎠 회전목마: ✅ 탑승 가능")

# 놀이기구 2: 범퍼카 (키 >= 120)
if height >= 120:
    print("🚗 범퍼카: ✅ 탑승 가능")
    count = count + 1
else:
    print("🚗 범퍼카: ❌ 탑승 불가 (120cm 이상)")

# 놀이기구 3: 롤러코스터 (키 >= 140)
if height >= 140:
    print("🎢 롤러코스터: ✅ 탑승 가능")
    count = count + 1
else:
    print("🎢 롤러코스터: ❌ 탑승 불가 (140cm 이상)")

# 놀이기구 4: 자이로드롭 (140 <= 키 <= 190, 연립부등식)
if 140 <= height <= 190:
    print("🗼 자이로드롭: ✅ 탑승 가능")
    count = count + 1
else:
    print("🗼 자이로드롭: ❌ 탑승 불가 (140~190cm)")

# 결과 요약
print("=" * 30)
print(f"🏆 탑승 가능: {count}개 / 4개")

    ⚠️ 주의할 점¶

    1. =과 ==을 헷갈리지 마세요!

    • = → 대입 (값을 넣는 것): height = 150
    • == → 비교 (같은지 확인): if height == 150:
    • >= → 이상 (크거나 같다): if height >= 140:

    2. if 다음 줄의 들여쓰기(인덴트)를 꼭 지키세요!

    파이썬은 들여쓰기로 코드 블록을 구분합니다. if 아래 실행할 코드는 반드시 스페이스 4칸 들여쓰기를 해야 합니다.

    ✅ 점검하기¶

    📝 정리하기: 이 장에서 배운 핵심을 확인해봅시다.

    1. (기본) 부등식 키 ≥ 140의 해에 해당하는 값을 모두 고르세요: 130, 140, 150, 200

    정답 확인 **140, 150, 200** ≥는 "이상"이므로 140을 **포함**합니다. 130은 140보다 작으므로 해가 아닙니다.

    2. (응용) 자이로드롭 조건 140 ≤ 키 ≤ 190을 만족하지 않는 키의 범위를 말해보세요.

    정답 확인 **키 < 140 또는 키 > 190** 즉, 139cm 이하이거나 191cm 이상이면 탑승할 수 없습니다. 연립부등식의 해가 아닌 영역이죠.

    3. (심화 · 도전!) 놀이기구에 나이 조건도 추가해봅시다. 롤러코스터가 "키 ≥ 140 그리고 나이 ≥ 10"이라면, if문을 어떻게 작성할까요?

    정답 확인 
    if height >= 140 and age >= 10:
    print("탑승 가능!")
else:
    print("탑승 불가!")
    두 부등식이 **동시에** 성립해야 하므로 `and`로 연결합니다. 이것이 바로 **연립부등식**의 코드 표현입니다!
