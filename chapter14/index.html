    참일까 거짓일까 — 명제와 논리 게이트¶

    Part 5. 공통수학2 — 집합과 명제, 데이터를 분류하다 | 14차시 (50분)

    🎯 이 장에서 배우는 것¶

    • 명제의 참·거짓을 판별하고, 프로그래밍의 True/False와 연결할 수 있다
    • AND, OR, NOT 논리 연산을 일상 예시와 진리표로 설명할 수 있다
    • 엔트리에서 논리 게이트 시뮬레이터를 만들어 입력에 따른 출력을 확인할 수 있다

    📚 핵심 개념¶

    개념 1: 명제 — 참 또는 거짓을 판별할 수 있는 문장¶

    비유로 시작 🐱

    "모든 고양이는 날 수 있다." — 이 문장, 참일까요 거짓일까요?

    누구나 거짓이라고 대답할 수 있죠. 이렇게 참인지 거짓인지 명확하게 판별할 수 있는 문장을 수학에서는 명제라고 부릅니다.

    정확한 정의

    명제(Proposition): 참(True) 또는 거짓(False) 중 하나의 값을 가지는 문장. 컴퓨터에서는 참을 1(또는 True), 거짓을 0(또는 False)으로 표현합니다.

    예시로 확인 ✏️

    • ✅ "3은 홀수이다." → 명제 O (참)
    • ✅ "서울은 일본의 수도이다." → 명제 O (거짓)
    • ❌ "이 피자 정말 맛있다!" → 명제 X (사람마다 다름, 판별 불가)
    • ❌ "x는 5보다 크다." → 명제 X (x 값을 모르면 판별 불가 — 이것은 조건문이라 부릅니다)

    💡 알아보기: 컴퓨터의 if 문에서 조건이 True이면 실행하고 False이면 건너뛰는 것, 바로 명제의 참·거짓 판별과 같은 원리입니다!

    개념 2: 논리 게이트 — AND, OR, NOT¶

    컴퓨터 내부에서는 0과 1만으로 모든 판단을 처리합니다. 이때 사용하는 기본 도구가 논리 게이트입니다.

    비유로 시작 💡

    방에 전등이 하나 있고, 스위치가 두 개 있다고 상상해 보세요.

    • AND 게이트: 스위치 A 그리고 스위치 B, 둘 다 켜야 전등이 켜집니다
    • OR 게이트: 스위치 A 또는 스위치 B, 하나만 켜도 전등이 켜집니다
    • NOT 게이트: 스위치가 켜져 있으면 끄고, 꺼져 있으면 켭니다 (반대로 뒤집기!)
    flowchart LR subgraph AND["🔒 AND 게이트"] A1["스위치 A"] --> G1["둘 다 ON?"] B1["스위치 B"] --> G1 G1 --> L1["💡 전등"] end subgraph OR["🔓 OR 게이트"] A2["스위치 A"] --> G2["하나라도 ON?"] B2["스위치 B"] --> G2 G2 --> L2["💡 전등"] end subgraph NOT["🔄 NOT 게이트"] A3["스위치 A"] --> G3["반대로!"] G3 --> L3["💡 전등"] end

    진리표로 정리

    진리표란 가능한 모든 입력 조합에 대해 출력을 정리한 것입니다.

    AND — 둘 다 참이어야 참 - A = 0, B = 0 → 출력 0 - A = 0, B = 1 → 출력 0 - A = 1, B = 0 → 출력 0 - A = 1, B = 1 → 출력 1 ✅

    OR — 하나만 참이면 참 - A = 0, B = 0 → 출력 0 - A = 0, B = 1 → 출력 1 ✅ - A = 1, B = 0 → 출력 1 ✅ - A = 1, B = 1 → 출력 1 ✅

    NOT — 반대로 뒤집기 - A = 0 → 출력 1 - A = 1 → 출력 0

    💡 생각해보기: 일상에서 AND와 OR를 찾아볼까요? "아이디 그리고 비밀번호가 맞아야 로그인" → AND! "현금 또는 카드로 결제 가능" → OR!

    🔨 따라하기: 엔트리 논리 게이트 시뮬레이터¶

    두 개의 스위치를 클릭하면 AND/OR/NOT 결과가 전구로 표시되는 시뮬레이터를 만들어 봅시다.

    Step 1: 변수 준비하기¶

    엔트리에서 다음 변수를 만드세요.

    • 스위치A → 초깃값 0
    • 스위치B → 초깃값 0
    • 결과 → 초깃값 0
    • 게이트모드 → 초깃값 "AND"

    Step 2: 스위치 토글 만들기¶

    스위치A 오브젝트(스프라이트)를 클릭하면 0 ↔ 1이 전환되도록 합니다.

    [이 오브젝트를 클릭했을 때]
만약 (스위치A) = 0 이라면
    스위치A 를 1 로 정하기
아니면
    스위치A 를 0 로 정하기

    스위치B 오브젝트에도 같은 방식으로 스위치B 변수를 토글합니다.

    Step 3: AND 게이트 로직 작성¶

    [▶ 시작 버튼을 클릭했을 때]
계속 반복하기 {
    만약 (게이트모드) = "AND" 이라면 {
        만약 (스위치A) = 1 그리고 (스위치B) = 1 이라면
            결과 를 1 로 정하기
        아니면
            결과 를 0 로 정하기
    }
}

    핵심은 그리고 블록입니다. 엔트리의 그리고가 바로 AND 연산이에요!

    Step 4: OR, NOT 모드 추가¶

    같은 반복 안에 이어서 작성합니다.

        만약 (게이트모드) = "OR" 이라면 {
        만약 (스위치A) = 1 또는 (스위치B) = 1 이라면
            결과 를 1 로 정하기
        아니면
            결과 를 0 로 정하기
    }

    만약 (게이트모드) = "NOT" 이라면 {
        만약 (스위치A) = 0 이라면
            결과 를 1 로 정하기
        아니면
            결과 를 0 로 정하기
    }

    Step 5: 전구 오브젝트에 반응 연결¶

    전구 스프라이트에 다음 코드를 넣습니다.

    [▶ 시작 버튼을 클릭했을 때]
계속 반복하기 {
    만약 (결과) = 1 이라면
        모양을 "전구_켜짐" 으로 바꾸기
    아니면
        모양을 "전구_꺼짐" 으로 바꾸기
}

    🎉 완성! 스위치를 클릭하며 AND, OR, NOT의 결과를 눈으로 확인해 보세요.

    📝 전체 코드 (엔트리 의사코드 정리)¶

    # === 변수 초기화 ===
스위치A = 0,  스위치B = 0,  결과 = 0,  게이트모드 = "AND"

# === 스위치A 오브젝트 ===
[클릭 시] 스위치A = (스위치A가 0이면 1, 아니면 0)

# === 스위치B 오브젝트 ===
[클릭 시] 스위치B = (스위치B가 0이면 1, 아니면 0)

# === 판정 (메인 루프) ===
계속 반복:
  AND 모드 → 결과 = 스위치A 그리고 스위치B
  OR  모드 → 결과 = 스위치A 또는 스위치B
  NOT 모드 → 결과 = 스위치A의 반대

# === 전구 오브젝트 ===
계속 반복:
  결과가 1이면 전구_켜짐, 아니면 전구_꺼짐

    ⚠️ 주의할 점¶

    1. "의견"은 명제가 아닙니다! "수학은 재미있다"처럼 사람마다 답이 다른 문장은 참·거짓을 판별할 수 없으므로 명제가 아닙니다.
    2. AND와 OR를 헷갈리지 마세요! AND는 "둘 다"여야 참, OR는 "하나만"이어도 참입니다. 일상어 "또는"과 프로그래밍의 OR는 같은 뜻이에요.

    ✅ 점검하기¶

    기본 문제 1. 다음 중 명제인 것을 모두 고르세요.

    ⓐ "지구는 평평하다." ⓑ "오늘 날씨 좋다!" ⓒ "7은 짝수이다." ⓓ "x + 2 = 5"

    정답 확인 **ⓐ, ⓒ** — ⓐ는 거짓이지만 판별 가능하므로 명제, ⓒ도 거짓인 명제입니다. ⓑ는 주관적 의견, ⓓ는 x 값에 따라 달라지는 조건문이므로 명제가 아닙니다.

    기본 문제 2. A = 1, B = 0일 때 AND, OR, NOT(A)의 결과를 각각 구하세요.

    정답 확인 - **AND**: 1 그리고 0 → **0** - **OR**: 1 또는 0 → **1** - **NOT(A)**: 1의 반대 → **0**

    응용 문제 3. OR 게이트의 진리표에서 출력이 0이 되는 경우는 몇 가지이고, 그때 A와 B의 값은?

    정답 확인 **1가지** — A = 0, B = 0일 때만 출력이 0입니다.

    🚀 도전 문제. XOR(배타적 OR) 게이트는 "A와 B가 서로 다를 때만 1"을 출력합니다. 엔트리에서 이를 구현하려면 어떤 조건을 써야 할까요? (힌트: 그리고, 또는, 아니다 블록을 조합해 보세요!)

    정답 확인 **XOR = (A 또는 B) 그리고 (A 그리고 B)가 아닌 것** 엔트리 코드로 표현하면: 
    만약 ((스위치A = 1 또는 스위치B = 1) 그리고
      ((스위치A = 1 그리고 스위치B = 1)이 아니다)) 이라면
    결과 를 1 로 정하기
아니면
    결과 를 0 로 정하기
    즉, "둘 중 하나는 켜져 있지만 둘 다 켜진 건 아닌" 상태일 때만 전구가 켜집니다!

    정리하기 📌 - 명제 = 참 또는 거짓을 판별할 수 있는 문장 (컴퓨터에서 True/False) - AND = 둘 다 참이어야 참 | OR = 하나만 참이면 참 | NOT = 반대로 뒤집기 - 컴퓨터의 모든 판단은 이 세 가지 논리 게이트의 조합으로 이루어집니다
