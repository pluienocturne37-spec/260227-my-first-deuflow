    검색은 집합이다 — 교집합·합집합으로 필터 만들기¶

    Part 5. 공통수학2 — 집합과 명제, 데이터를 분류하다

    🎯 이 장에서 배우는 것¶

    • 집합의 교집합·합집합·차집합을 검색 필터 상황에서 설명할 수 있다
    • 벤다이어그램을 그려 두 집합의 관계를 시각적으로 표현할 수 있다
    • 엔트리에서 음식 검색 필터(매운맛 ∩ 면 요리)를 코드로 만들 수 있다

    📚 핵심 개념¶

    💡 생각해보기¶

    배달 앱을 켜고 음식을 주문할 때, '한식' 버튼과 '매운맛' 버튼을 동시에 누르면 어떤 결과가 나올까요? 한식 전체도, 매운 음식 전체도 아닌 — 한식이면서 동시에 매운 음식만 화면에 뜹니다. 이 "동시에 만족"이라는 행위, 수학에서는 뭐라고 부를까요?

    바로 집합 연산입니다!

    개념 1: 교집합(∩)과 합집합(∪) — AND 필터와 OR 필터¶

    1. 비유로 시작

    교집합은 마치 배달 앱에서 필터 두 개를 동시에 거는 것과 같아요. "매운맛 그리고 면 요리" → 둘 다 만족하는 결과만 나옵니다.

    합집합은 마치 필터를 느슨하게 거는 것과 같아요. "매운맛 또는 면 요리" → 둘 중 하나라도 해당하면 전부 나옵니다.

    2. 정확한 정의

    • 교집합 A ∩ B: 집합 A에도 속하고 집합 B에도 속하는 원소들의 모임 (AND)
    • 합집합 A ∪ B: 집합 A에 속하거나 집합 B에 속하는 원소들의 모임 (OR)
    • 차집합 A − B: 집합 A에는 속하지만 집합 B에는 속하지 않는 원소들의 모임 (제외 버튼)

    3. 예시로 확인

    우리 학교 앞 음식 8개를 두 가지 기준으로 분류해봅시다.

    • A (매운맛): {떡볶이, 짬뽕, 불닭볶음면, 마라탕}
    • B (면 요리): {짬뽕, 불닭볶음면, 잔치국수, 파스타}
    graph LR subgraph "A ∩ B (매운맛 AND 면 요리)" C1[짬뽕] C2[불닭볶음면] end
    • A ∩ B = {짬뽕, 불닭볶음면} → 매운 면 요리 2개
    • A ∪ B = {떡볶이, 짬뽕, 불닭볶음면, 마라탕, 잔치국수, 파스타} → 6개
    • A − B = {떡볶이, 마라탕} → 매운데 면은 아닌 것

    개념 2: 벤다이어그램으로 보는 집합 관계¶

    벤다이어그램은 집합의 관계를 원 두 개의 겹침으로 표현하는 그림입니다.

    flowchart TB subgraph U["전체 음식 (전체집합 U)"] subgraph A_only["A만 (매운맛만)"] a1["떡볶이"] a2["마라탕"] end subgraph AB["A ∩ B (교집합)"] ab1["짬뽕"] ab2["불닭볶음면"] end subgraph B_only["B만 (면 요리만)"] b1["잔치국수"] b2["파스타"] end rest["김밥, 돈까스 (어디에도 안 속함)"] end

    🔎 알아보기: 벤다이어그램에서 색칠하는 영역에 따라 연산이 달라집니다. - 겹치는 가운데만 색칠 → 교집합 - 두 원 전체를 색칠 → 합집합 - 왼쪽 원에서 겹치는 부분을 빼고 색칠 → 차집합 A − B

    🔨 따라하기: 음식 검색 필터 만들기¶

    엔트리(Entry)에서 음식 데이터 리스트를 만들고, 사용자가 선택한 조건에 맞는 결과만 출력하는 필터를 만들어봅시다. 아래 코드는 Python 스타일로 작성했으며, 엔트리 블록 코딩으로도 동일하게 구현할 수 있습니다.

    Step 1: 음식 데이터 준비하기¶

    # 음식 이름 리스트
foods = ["떡볶이", "짬뽕", "불닭볶음면", "마라탕", "잔치국수", "파스타", "김밥", "돈까스"]

# 속성별 집합 만들기
spicy = {"떡볶이", "짬뽕", "불닭볶음면", "마라탕"}     # 매운맛
noodle = {"짬뽕", "불닭볶음면", "잔치국수", "파스타"}   # 면 요리

    Step 2: 교집합(AND 필터) 구현하기¶

    # 매운맛 AND 면 요리 → 교집합
result_and = spicy & noodle   # Python에서 &는 교집합
print("매운 면 요리:", result_and)

    실행 결과: 

    매운 면 요리: {'짬뽕', '불닭볶음면'}

    Step 3: 합집합(OR 필터) 구현하기¶

    # 매운맛 OR 면 요리 → 합집합
result_or = spicy | noodle    # Python에서 |는 합집합
print("매운맛 또는 면 요리:", result_or)

    실행 결과: 

    매운맛 또는 면 요리: {'떡볶이', '짬뽕', '불닭볶음면', '마라탕', '잔치국수', '파스타'}

    Step 4: 차집합(제외 필터) 구현하기¶

    # 매운맛인데 면 요리는 제외 → 차집합
result_exclude = spicy - noodle   # Python에서 -는 차집합
print("매운맛 (면 제외):", result_exclude)

    실행 결과: 

    매운맛 (면 제외): {'떡볶이', '마라탕'}

    Step 5: 사용자 입력으로 필터 선택하기¶

    print("검색 조건을 선택하세요:")
print("1: 매운맛 AND 면 요리")
print("2: 매운맛 OR 면 요리")
print("3: 매운맛 (면 제외)")

choice = input("번호 입력: ")

if choice == "1":
    print("결과:", spicy & noodle)
elif choice == "2":
    print("결과:", spicy | noodle)
elif choice == "3":
    print("결과:", spicy - noodle)
else:
    print("잘못된 입력입니다.")

    📝 전체 코드¶

    # === 음식 검색 필터 프로그램 ===

# 1. 데이터 준비
foods = ["떡볶이", "짬뽕", "불닭볶음면", "마라탕", "잔치국수", "파스타", "김밥", "돈까스"]
spicy = {"떡볶이", "짬뽕", "불닭볶음면", "마라탕"}
noodle = {"짬뽕", "불닭볶음면", "잔치국수", "파스타"}

# 2. 집합 연산 결과 미리 확인
print("== 집합 연산 결과 ==")
print("교집합 (AND):", spicy & noodle)
print("합집합 (OR) :", spicy | noodle)
print("차집합 (제외):", spicy - noodle)
print()

# 3. 사용자 필터 선택
print("검색 조건을 선택하세요:")
print("1: 매운맛 AND 면 요리")
print("2: 매운맛 OR 면 요리")
print("3: 매운맛 (면 제외)")

choice = input("번호 입력: ")

if choice == "1":
    print("🔍 결과:", spicy & noodle)
elif choice == "2":
    print("🔍 결과:", spicy | noodle)
elif choice == "3":
    print("🔍 결과:", spicy - noodle)
else:
    print("잘못된 입력입니다.")

    ⚠️ 주의할 점¶

    1. 교집합과 합집합을 헷갈리지 마세요!

    "매운맛 그리고 면 요리"는 범위가 좁아지는 교집합(∩)입니다. "매운맛 또는 면 요리"는 범위가 넓어지는 합집합(∪)입니다. 일상에서 "이것도 저것도"라고 말하면 합집합처럼 들리지만, 프로그래밍에서 AND는 둘 다 만족이라 결과가 더 적어집니다.

    2. Python의 집합은 중괄호 {}를 씁니다

    리스트 []와 집합 {}를 구분하세요. 집합은 중복을 자동으로 제거하고, &, |, - 연산자를 바로 쓸 수 있습니다.

    ✅ 점검하기¶

    기본 문제¶

    1. A = {1, 2, 3, 4, 5}, B = {3, 4, 5, 6, 7}일 때 A ∩ B와 A ∪ B를 구하세요.

    정답 확인 A ∩ B = {3, 4, 5} (둘 다 속하는 원소), A ∪ B = {1, 2, 3, 4, 5, 6, 7} (하나라도 속하는 원소)

    2. 배달 앱에서 "중식" 필터와 "1만 원 이하" 필터를 동시에 걸었습니다. 이것은 교집합, 합집합, 차집합 중 무엇인가요?

    정답 확인 **교집합(∩)**입니다. 두 조건을 **동시에(AND)** 만족하는 결과만 보여주기 때문입니다.

    응용 문제¶

    3. A = {사과, 바나나, 딸기, 포도}, B = {딸기, 포도, 수박, 참외}일 때, A − B를 구하고, 이것이 검색 필터에서 어떤 의미인지 설명하세요.

    정답 확인 A − B = {사과, 바나나}. 이것은 "A에 해당하는 과일 중에서 B에 해당하는 것은 **제외**"하는 필터입니다. 배달 앱의 "~제외" 버튼과 같은 역할입니다.

    🚀 도전 문제¶

    4. 음식 집합을 세 개로 확장해봅시다. 매운맛(A), 면 요리(B), 국물 있음(C)일 때, "매운 국물 면 요리"를 집합 기호로 어떻게 쓸까요? 그리고 코드에서 어떻게 구현하면 될까요?

    정답 확인 **A ∩ B ∩ C** (세 집합의 교집합). 코드로는 `spicy & noodle & soup`으로 구현합니다. 결과 예시: 짬뽕처럼 세 조건을 모두 만족하는 음식만 나옵니다.

    📌 정리하기

    • 교집합(∩) = AND 필터 → 조건을 많이 걸수록 결과가 좁아진다
    • 합집합(∪) = OR 필터 → 조건을 많이 걸수록 결과가 넓어진다
    • 차집합(−) = 제외 필터 → 특정 조건을 빼는 역할
    • Python에서는 &, |, - 기호로 집합 연산을 바로 할 수 있다
